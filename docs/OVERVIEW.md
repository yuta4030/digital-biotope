## 1. 何を調べているのか

> **どういう条件なら多様な生態系が成り立つのか。**

出発点は「上位層は適応できる世界が狭い」という結果で、そこから
「では地球の幅広い多様性は何によって実現されたのか」「多様性は突然変異と
トライアンドエラーだけで出せるのか」に伸びた。

動くシミュレータを作ることは目的ではない。**実験で確かめるための装置**であって、
結論は毎回、数字を見るまで分からない。

## 2. 模型（実装の全体像）

### 1ステップで起きること

```
移動 → 捕食/採食 → 代謝 → 死亡 → 繁殖
```

- **草** はセルごとの資源。毎ステップ一定量ずつ上限まで回復する。
  エージェントではないので絶滅しない
- **動物** はエージェント。捕食関係は種定義の `preys` だけで決まり、
  シミュレーション側に種別の分岐は無い。種を足せば連鎖が伸びる
- 端はトーラス（壁にすると端に溜まって分布が歪む）
- 状態は Structure of Arrays（TypedArray）。乱数はすべてシード付き `rng.ts` を通る

実物は [src/core/step.ts](../src/core/step.ts) を読むのが早い。

### 系を支配している1本の式

```
草食動物の平衡個体数 ≒ 草の回復速度 × セル数 ÷ 実効代謝
実効代謝 = 基礎代謝 + 速度コスト × 移動速度 + 視野コスト × 視野
```

既定値なら `0.06 × 10800 ÷ 0.6 = 1080`。
**この模型で起きることの多くは、この式の帰結として説明がつく。**

- 代謝を下げると上限が上がり、そのぶん跳ね上がりが大きくなって振動が激しくなる
  （[04](reports/04-metabolism-stability.md)）
- 上の層はこの数の何分の一かになるので、頂点捕食者は谷で1〜5体まで落ちる
- 形質に代償が無いと上限まで走り去る。速度コスト0では速度が上限4.0のうち3.77まで上がる
  （[10](reports/10-speed-evolution.md)）

### つまみの一覧

| 軸 | 何をする | 入れた理由 | 出典 |
|---|---|---|---|
| 代謝 / 捕食利得 | 振動の激しさを決める | 共存域の探索 | [01](reports/01-coexistence-region.md) |
| 視野 | ランダムウォークをやめ、逃走→追跡→採餌の順で動く | 「見る」ことの価値を測る | [03](reports/03-vision-and-pursuit.md) |
| 空腹閾値 | 腹が減ったら逃走より採餌を優先する | 速度差なしで追跡を成立させる | [11](reports/11-hunger.md) |
| 行動コスト | 速度と視野に維持費をつける | 「代謝は低いほど得」の歪みを外す | [05](reports/05-activity-cost.md) |
| 草地のパッチ | 回復速度をセルごとに変える（平均は1に正規化） | 空間の不均質さ | [07](reports/07-grass-patches.md) |
| 死骸の還元 | 死んだ個体をその場の草に戻す | 循環を閉じる | [08](reports/08-corpse-recycling.md) |
| 死骸の半径 / デトリタス在庫 | 死骸を空間に撒く / 時間に均す | 集中の害の切り分け | [09](reports/09-detritus-buffer.md) |
| 変異（速度） | 速度を個体ごとの遺伝形質にする | 進化を入れる | [10](reports/10-speed-evolution.md) |
| 大量死 | 形質を見ない無作為な死 | 揺らぎの大きさのつまみ | [14](reports/14-mass-death.md) |

`mutation` と `disturbance` を書かない構成は**乱数を1つも消費しない**ので、
機構を足しても既存の結果はビット単位で変わらない。この回帰の約束は
10・11・12・14 のすべてで守られている。

## 3. 分かったこと（5本の筋）

### 筋1 — 縦には積めない。そしてそれは現実と合っている

草の生産量が草食の平衡個体数を決め、上の層はその何分の一かになる。
4層の頂点捕食者は谷で1〜5体まで落ちるので、**パラメータではなく偶然だけで消える。**
代謝0.55と0.65の間に崖があり（[02](reports/02-preset-validation.md)）、
既定値でも8回に1回崩壊する（[04](reports/04-metabolism-stability.md)）。

地球でも頂点捕食者は真っ先に絶滅する。**この脆さは模型の欠陥ではなく再現。**

そして、地球の種数は下と横に偏っている。数百万種いるのは昆虫・微生物・寄生者・植物で、
**同じ段の中で横に分かれている**。`3層 → 4層 → 5層` と積む方向は、
地球でも実際に窓が狭い方向だった。多様性を探すなら横を見るべきだった。

### 筋2 — 横の共存は自力で立たない

| | 結果 |
|---|---|
| 競合 | 捕食者を消すと **A 1298 / B 0**。強い方が競争排除する |
| 燃費（[05](reports/05-activity-cost.md)） | 共存するのは視野コスト 0.025〜0.030 の**ナイフエッジ** |
| パッチ（[07](reports/07-grass-patches.md)） | 不均質にすると共存が**さらに壊れた**（657対965 → 16対1606）|

**ニッチ軸が1本（草）しか無いことの必然。軸が1本なら勝者は1人しかいない。**
競合構成で共存が成り立つのは、捕食者が勝者だけを叩いているから（キーストーン捕食）。
つまりこの模型で横の多様性を支えているのは、いまのところ**外から入る非対称な圧力**だけ。

### 筋3 — 環境に構造を入れても、それを読む規則が噛み合わなければ効かない

07のパッチは典型。不均質さは確かにニッチを作ったが、**それを取ったのは目を持たない側**だった。
草を探して動く個体は餌の多い場所に集まって競争を激化させ、刈り残しも増える。
貪欲な採餌の規則が不均質さを活かせなかった。

死骸の還元（[08](reports/08-corpse-recycling.md)）は、対照を並べたら豊穣化と区別がつかず、
効いていたのは循環ではなく**空間の集中**だった（[09](reports/09-detritus-buffer.md)）。
しかもその集中の正体は「手が届く範囲の問題」——盤面に餌があっても、
1個体が1ステップに取れるのは採食量ぶんだけなので、山は大半の個体から届かない。
**空間の集中は、実質的に時間の遅延として効いていた。**

### 筋4 — 進化は探索空間の形に従うだけで、それ自体は多様性を生まない

速度を遺伝させると、集団は坂を下り切らず**内点の最適に収束する**
（捕食者ありで2.74、なしで1.11）。代償が landscape の形を作っている。
変異の強さは収束先を変えず、変えるのは到達時間と集団内のばらつきだけ。

予想していなかったのは**二つの最適の実在**。視野3で捕食圧を上げると、集団は
約0.78（目に頼る型）と約2.45（足に頼る型）のどちらかに落ち着き、中間に留まらない。
ただし1つの集団の中では単峰なので、**分岐であって多型ではない**
（[13](reports/13-escape.md) が遷移であることを裏づけた）。

共存させるには片方が増えるともう片方が有利になる仕組み（**負の頻度依存**）が要る。
この構成にはそれが無い。

### 筋5 — 揺らぎは局所最適から抜ける機会を作る。ただし両刃

置き直した前提はこう。

> **繁栄にはある程度の安定が必須で、その上で許容できる範囲の揺らぎが必要になる。**

希少な変異体は平衡状態では既存種の壁を越えられないが、既存種が谷に落ちた瞬間なら
食い込める。安定した平衡は、**居座っている側にとって最も守りが固い状態**でもある。

| 測ったこと | 結果 |
|---|---|
| 侵入（[12](reports/12-invasion.md)） | 揺らぎは不利な系統の通過率を**4倍**にする（山3.1% → 谷12.6%）|
| 非選択性 | 谷が足す量は有利さによらず 9〜11pp で一定。**有利な変異体しか通さない仕組みでは今いる丘を登ることしかできない**ので、非選択性は欠陥ではなく要件 |
| 脱出（[13](reports/13-escape.md)） | 41件の離脱のうち、個体数が上位25%の時期に起きたものは**0件** |
| 効いているのは谷（13） | 捕食者の頭数を揃えても谷は効き、谷を揃えると捕食圧は消える。**捕食圧は谷の逆数を見ていただけ** |
| もう一方の刃（[14](reports/14-mass-death.md)） | 侵入者を巻き添えから外すと定着率が上がる。**同じ谷の深さで比べても差が残る**（25% 対 18%）ので、これは「窓が開く頻度」ではなく「開いた窓で生き残れるか」の差 |

機構の見立ては「谷では1個体あたりの草が増えるので、**代償の高い形質が一時的に安くなる**」
（足に頼る型の実効代謝が 0.367 → 0.618 でほぼ倍）。
**ただしこれは解釈で、離脱時の1個体あたりの草はまだ測っていない。**

## 4. 一番痛い教訓 — 動かした覚えのない軸が動く

覆った結論5件のうち3件がこれ。**新しい軸を足すときは、それが何を一緒に動かすかを
数える手段も一緒に作る。**

| 軸 | 狙い | 一緒に動いたもの | どうしたか |
|---|---|---|---|
| 死骸の還元（08） | 循環を閉じる | **総エネルギー入力**（＝豊穣化） | `grassAdded` と `grassFromCorpses` を分けて数えて発覚 |
| デトリタス在庫（09） | 流入のばらつきだけ下げる | 総入力も同時に動く | 分離できず、結論を出さなかった |
| 捕食まわりのつまみ（13） | 揺らぎだけ動かす | 速度の丘の位置 | 分離を諦め、**同じ走行の中の谷と山**を対照にした |
| 大量死・全種（14） | 形質を見ないので丘は動かないはず | 捕食者も減る → 捕食圧が下がる → 丘が 2.70 → 2.25 | 対象を**草食だけ**に絞ると成立する |
| 大量死・強め（14） | 同上 | 草食が谷に落ちれば捕食者も餓死する | **中程度まで**なら使える |

08の「回復速度をいじっていないのだからエネルギー量は同じはず」と、
14の「形質を見ていないのだから丘は動かないはず」は**同じ形の間違い**。
2回踏んでいる。

### 指標そのものが嘘をつくパターン

| やったこと | 何が起きたか | 正しい見方 |
|---|---|---|
| 平均を見た | 絶滅は平均では予測できない | **谷を見る**。表には必ず `平均(最小-最大)` |
| 3シードで判断（04） | 非単調な機構を「発見」しかけ、8シードで消えた | **既定は8シード**。`7/8` と `8/8` の差は読み分けない |
| 崩壊した試行を混ぜた（09） | 崩壊すると変動係数が跳ね上がる。**「高いから崩壊した」ではなく「崩壊したから高い」** | 崩壊後のデータを混ぜない |
| 変動係数で揺らぎを代弁した（14） | 0.494 対 0.534 とほぼ同じなのに、谷の深さは 0.20 対 0.04 で5倍違う | 定着率が追随するのは**谷の深さ**のほう |
| 周期のある系で相関を読んだ（08） | ラグを振ったら**符号が反転し続けた**。相関は周期を写していただけ | 相関を機構の証拠にしない |
| 比を平均した（13） | 分母が谷で小さくなる量の平均は、谷の深さに支配される。結論の向きが逆になった | 比の平均を取らない |
| 短い走行の生存率で安全と判断（14） | 崩壊確率は走行が長いほど積み上がる。8000歩で `8/8` が90000歩で `2/8` | **使う予定の長さで確かめる** |

そして [03](reports/03-vision-and-pursuit.md) で3回。
走査順のバイアスが「群れて非効率になる」に、インデックス構築のタイミングが
「視野があると捕食者が不利になる」に見えた。どれも生態学的にありえそうな話だった。
**新しい挙動が出たら、まず実装を疑う。**

## 5. まだ測れていないこと

結論として書けていない穴。ここを埋めないまま先へ進むと、後で同じ場所に戻ってくる。

- **揺らぎの量に対する応答の形。** 予想表（小さすぎる＝通らない / 中くらい＝通る /
  大きすぎる＝殺される）のうち、14 で検定できたのは**前半だけ**。
  後半で定着率が折り返す点は無く、代わりに**世界のほうが先に消える**
  （900歩×90% で8シード中7〜8が崩壊）。
  「大きすぎる揺らぎは変異体を殺す」の前に「大きすぎる揺らぎは系を殺す」が来る
- **脱出の成功率。** 13 が数えたのは離脱で、着地ではない。
  利得22では19件が離脱して、高い丘に着いたのは2件しかない
- **谷で何が起きているかの直接の証拠。** 離脱時の1個体あたりの草は未測定
- **通した先に別の進化を歩めるか。** 12 の侵入者は固定の遺伝子型で、
  代謝という軸に第二の丘が無い。不利な侵入者が40/40消えたのは反証ではなく設定の帰結
- **代謝の変異。** 10 は速度でやった。単調な坂に崖が付いた軸なので、
  内点で釣り合う速度とは別の形が出るはず

### 検討して「やらない」と決めたもの

- **個体へのバッファ（休眠・寿命延長）** — 生きている間はそれ自体がバッファとして
  機能している。軸を増やすと揺らぎとバッファの効果が混ざる
- **種ごとの応答の差を手で作る** — 変異システムの中で自然に出るべきもの

## 6. 次の一手

**負の頻度依存（kill-the-winner）。** 寄生・感染症に相当する、増えた種ほど叩かれる圧力。

理由は2つある。

1. **筋4の出口。** 10 が「二つの戦略を共存させるには負の頻度依存が要る。
   この構成にはそれが無い」で終わっていて、13 がその分岐は遷移であって共存ではないと
   裏づけた。共存を作る機構を入れるのが筋。地球で最も強力な多様性の維持機構でもある
2. **筋5で残った交絡の出口。** 増えた種ほど叩かれる圧力は捕食とは別系統で個体数を振るので、
   **丘の位置を動かさずに揺らぎを動かせる**可能性がある

入れるときの条件は第4節がそのまま効く。**「それが何を一緒に動かすか」を数える手段を
先に作る**こと。14 で言えば、捕食者の頭数と速度の収束先を毎回出す形にしておけば、
全種を叩いたときの丘のずれはその場で見えていた。

その先の候補は [DIRECTION](DIRECTION.md) の末尾に列挙してある
（捕食以外の種間関係、分解者を種として実装する、代謝の変異）。
