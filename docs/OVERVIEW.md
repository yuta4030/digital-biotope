## 1. 何を調べているのか

> **どういう条件なら多様な生態系が成り立つのか。**

出発点は「上位層は適応できる世界が狭い」という結果で、そこから
「では地球の幅広い多様性は何によって実現されたのか」「多様性は突然変異と
トライアンドエラーだけで出せるのか」に伸びた。

動くシミュレータを作ることは目的ではない。**実験で確かめるための装置**であって、
結論は毎回、数字を見るまで分からない。

## 2. 模型（実装の全体像）

### 1ステップで起きること

```
移動 → 捕食/採食 → 代謝 → 死亡 → 繁殖
```

- **草** はセルごとの資源。毎ステップ一定量ずつ上限まで回復する。
  エージェントではないので絶滅しない
- **動物** はエージェント。捕食関係は種定義の `preys` だけで決まり、
  シミュレーション側に種別の分岐は無い。種を足せば連鎖が伸びる
- 端はトーラス（壁にすると端に溜まって分布が歪む）
- 状態は Structure of Arrays（TypedArray）。乱数はすべてシード付き `rng.ts` を通る

実物は [src/core/step.ts](../src/core/step.ts) を読むのが早い。

### 系を支配している1本の式

```
草食動物の平衡個体数 ≒ 草の回復速度 × セル数 ÷ 実効代謝
実効代謝 = 基礎代謝 + 速度コスト × 移動速度 + 視野コスト × 視野
```

既定値なら `0.06 × 10800 ÷ 0.6 = 1080`。
**この模型で起きることの多くは、この式の帰結として説明がつく。**

- 代謝を下げると上限が上がり、そのぶん跳ね上がりが大きくなって振動が激しくなる
  （[04](reports/04-metabolism-stability.md)）
- 上の層はこの数の何分の一かになるので、頂点捕食者は谷で1〜5体まで落ちる
- 形質に代償が無いと上限まで走り去る。速度コスト0では速度が上限4.0のうち3.77まで上がる
  （[10](reports/10-speed-evolution.md)）

### つまみの一覧

| 軸 | 何をする | 入れた理由 | 出典 |
|---|---|---|---|
| 代謝 / 捕食利得 | 振動の激しさを決める | 共存域の探索 | [01](reports/01-coexistence-region.md) |
| 視野 | ランダムウォークをやめ、逃走→追跡→採餌の順で動く | 「見る」ことの価値を測る | [03](reports/03-vision-and-pursuit.md) |
| 空腹閾値 | 腹が減ったら逃走より採餌を優先する | 速度差なしで追跡を成立させる | [11](reports/11-hunger.md) |
| 行動コスト | 速度と視野に維持費をつける | 「代謝は低いほど得」の歪みを外す | [05](reports/05-activity-cost.md) |
| 草地のパッチ | 回復速度をセルごとに変える（平均は1に正規化） | 空間の不均質さ | [07](reports/07-grass-patches.md) |
| 死骸の還元 | 死んだ個体をその場の草に戻す | 循環を閉じる | [08](reports/08-corpse-recycling.md) |
| 死骸の半径 / デトリタス在庫 | 死骸を空間に撒く / 時間に均す | 集中の害の切り分け | [09](reports/09-detritus-buffer.md) |
| 変異（速度） | 速度を個体ごとの遺伝形質にする | 進化を入れる | [10](reports/10-speed-evolution.md) |
| 変異（視野） | 視野を個体ごとの遺伝形質にする＝**採食規則が遺伝する** | 規則の違いが変異から出るか | [22](reports/22-vision-evolution.md) |
| 大量死 | 形質を見ない無作為な死 | 揺らぎの大きさのつまみ | [14](reports/14-mass-death.md) |
| 地形 | 移動コストをセルごとに変える（平均は1に正規化） | 環境を形質と結合させる | [20](reports/20-terrain.md) |
| 資源2本 | 草を2本に分ける（総生産量と総容量は固定） | ニッチ軸そのものを増やす | [23](reports/23-two-resources.md) |

`mutation` と `disturbance` を書かない構成は**乱数を1つも消費しない**ので、
機構を足しても既存の結果はビット単位で変わらない。この回帰の約束は
10・11・12・14・22 のすべてで守られている。

## 3. 分かったこと（6本の筋）

### 筋1 — 縦には積めない。そしてそれは現実と合っている

草の生産量が草食の平衡個体数を決め、上の層はその何分の一かになる。
4層の頂点捕食者は谷で1〜5体まで落ちるので、**パラメータではなく偶然だけで消える。**
代謝0.55と0.65の間に崖があり（[02](reports/02-preset-validation.md)）、
既定値でも8回に1回崩壊する（[04](reports/04-metabolism-stability.md)）。

地球でも頂点捕食者は真っ先に絶滅する。**この脆さは模型の欠陥ではなく再現。**

そして、地球の種数は下と横に偏っている。数百万種いるのは昆虫・微生物・寄生者・植物で、
**同じ段の中で横に分かれている**。`3層 → 4層 → 5層` と積む方向は、
地球でも実際に窓が狭い方向だった。多様性を探すなら横を見るべきだった。

### 筋2 — 横の共存は、採食規則が違えば自力で立つ

**この節は [21](reports/21-r-star.md) で書き直した。以前は「横の共存は自力で立たない」で、
根拠3つのうち2つが要約の段階で意味を変えていた。**

決めているのは **R\***（その種が単独で資源をどこまで引き下げられるか）。
1本の資源をめぐる競争では R\* の低いほうが勝つ——相手がもう減り始める水準で
まだ増えられるので。

| | 結果 |
|---|---|
| 競合 | 捕食者を消すと **A 1298 / B 0**。R\* が 0.688 対 0.892 で低いほうが勝つ |
| 燃費（[05](reports/05-activity-cost.md)・[21](reports/21-r-star.md)） | **捕食者なしで共存する。** 30000歩・相互侵入が両方向・どちらから始めても同じ平衡（478 : 1055）| 
| パッチ（[07](reports/07-grass-patches.md)・21） | 不均質にすると壊れる。ただし**30000歩まで見えない**（6000歩で 8/8、30000歩で 3/8・5/8）|

**軸は1本ではなかった。** 燃費構成の2種は視野の有無だけが違い、
**同じ資源から同じ量のエネルギーを違う取り方で取っている**——無警戒型は94%の歩で
0.423 ずつ、警戒型は46%の歩で 1.032 ずつ（歩あたりの摂取は両種とも実効代謝と
比 1.00 で一致）。制限しているものが違う：「草のあるセルの密度」と「濃いセルの密度」。

そして**2本目の軸は世界の性質ではない**。草はスカラー1本で全セル一様に回復する。
標準現存量のばらつきは**採食そのものが作っている**——さっき食べられたセルは空で、
誰も来ていないセルは溜まっている。**消費者の集合が生成した統計量が軸になっている。**

R\* が壊れるのは規則をまたいだときだけで、同じ規則の中では実効代謝についてくる
（比 1.32〜1.53）。視野を持つと 5.42 に跳ねる——豊かなセルを追いかけて痩せたセルを
刈り残すため。07 の刈り残し `2.54 対 0.53` は R\* を測っていた。

### ただし、その軸の上に留まれるのは規則が遺伝しないから

**[22](reports/22-vision-evolution.md) で分かった。この節を読むときの必須の但し書き。**

上の共存は `visionRange` が**種の定数**である場合の話で、視野を遺伝形質にすると
**6000ステップで片方が絶滅する**。捕食者なしなら無警戒型が視野0から0.79へ動いて勝ち、
捕食者ありなら警戒型が2.93のまま勝つ。どちらでも共存は消える。

壊れ方は「2種が同じ点に寄って中立になる」ではなかった。**中間へ動いた側が
両方の資源を取る**——視野0.79 の個体は78%の歩で半径1を持つので、薄いセルを
拾いながら濃いセルも取りに行ける。専門家の取り分だけが消える。

そして**生き残った側は、1種だけを進化させたときの平衡にビタ一致する**
（捕食者なし 0.80 / 1544体、捕食者あり 2.93 / 832体）。
21 の共存平衡の合計 1533体とほぼ同じ量を、2つの規則ではなく1つで回収している。

> **軸があることと、その軸の上に2種が留まれることは別物。**

### ただし「留まれない」はきつすぎた。窓には幅がある

**[25](reports/25-low-hill-check.md) で分かった。** 22 は終点（視野0.79）しか
見ていない。中間型を**手で置いて変異を切る**と、崩壊は点ではなく坂になる。

| 無警戒型の視野 | 警戒型（視野3） | 警戒型の取り分 |
|---|---|---|
| 0.00 | 481 | 31%（21 の共存の再現）|
| 0.25 | 267 | 17% |
| 0.50 | 78 | 5% |
| 0.80 | **0** | 0% |

**0.25 と 0.50 は本物の共存**——30000歩・相互侵入が両方向・どちらから始めても
同じ平衡（21 とまったく同じ判定）。陰性対照の 0.80 は両方向とも排除される。

だから 22 の「共存を支えていたのは軸の上を動けないこと」は正確ではない。
**両端に固定されている必要はなく、片方が 0.5 あたりより下に留まればいい。**
壊れているのは別の場所で、**1種を進化させた着地点が 0.81 で、窓の外にある**。

> 留まれる範囲は存在する。ただし進化がそこへ行かない。
> 課題は「軸の上を動けなくする」ではなく「**着地点を 0.3 ほど下へ動かす**」。

（窓の端は 0.50 と 0.80 の間。詰めていない）

キーストーン捕食（外から入る非対称な圧力）はこれとは別の道で、手で書かなくても出せる（→筋6）。

### 筋3 — 環境に構造を入れても、それを読む規則が噛み合わなければ効かない

07のパッチは典型。不均質さは確かにニッチを作ったが、**それを取ったのは目を持たない側**だった。
草を探して動く個体は餌の多い場所に集まって競争を激化させ、刈り残しも増える。
貪欲な採餌の規則が不均質さを活かせなかった。

**規則の側を噛み合わせても足りなかった。** [20](reports/20-terrain.md) は
移動の代償を不均質にした。コストは形質に直結しているので「誰がどこを得意とするか」は
定義上分かれている。それでも**分かれるのは個体数だけ**（平地268 対 険地221）で、
形質は分かれない（速度 2.80 対 2.77、集団内のばらつきは0.27）。
捕食者も進化させると捕食者は山を捨てるので**山は捕食圧の低い場所になる**が
（152 対 79）、それでも草食の速度差は集団内のばらつきに埋もれる。

効かない理由は**資源の打ち消し**だった。草は一様に回復するので、
険しいセルほど個体が減り、そのぶん食べ残しが溜まる。実効代謝は平地の1.84倍でも
1個体あたりの草は1.49倍濃い。**コストの空間勾配は標準現存量の空間勾配に
変換されて、適応度の勾配としては残らない。**

これは平衡であることの意味そのもので、**空間的な環境の不均質さは消費者が
再分布できる限り自動的に均される**。均された状態は定義上どこでも適応度が等しく、
等しければ形質にかかる選択差もゼロ。だから**起伏を強くしても効かない**
（実現率は強さ0.6で27%、0.9で25%と変わらない）。

07と20は同じ均衡の入口と出口を別々に見ていた——07は「みんな良い場所に寄る」、
20は「寄った結果、良い場所の取り分が減る」。

死骸の還元（[08](reports/08-corpse-recycling.md)）は、対照を並べたら豊穣化と区別がつかず、
効いていたのは循環ではなく**空間の集中**だった（[09](reports/09-detritus-buffer.md)）。
しかもその集中の正体は「手が届く範囲の問題」——盤面に餌があっても、
1個体が1ステップに取れるのは採食量ぶんだけなので、山は大半の個体から届かない。
**空間の集中は、実質的に時間の遅延として効いていた。**

### 筋4 — 進化は探索空間の形に従うだけで、それ自体は多様性を生まない

速度を遺伝させると、集団は坂を下り切らず**内点の最適に収束する**
（捕食者ありで2.74、なしで1.11）。代償が landscape の形を作っている。
変異の強さは収束先を変えず、変えるのは到達時間と集団内のばらつきだけ。

予想していなかったのは**二つの最適の実在**。視野3で捕食圧を上げると、集団は
約0.78（目に頼る型）と約2.45（足に頼る型）のどちらかに落ち着き、中間に留まらない。
ただし1つの集団の中では単峰なので、**分岐であって多型ではない**
（[13](reports/13-escape.md) が遷移であることを裏づけた）。

共存させるには片方が増えるともう片方が有利になる仕組み（**負の頻度依存**）が要る。
この構成にはそれが無い。

**[22](reports/22-vision-evolution.md) が、これを採食規則という別の軸で引き直した。**
視野を遺伝させると丘はやはり2つ（約0.78と約2.9）出るが、集団の分布は
全シードで単峰。**規則の違いも変異からは出てこない。**

そして 22 は速度では見えなかったものを1つ足した。**変異の刻みが行き先を決める**
（σ=0.05 なら低い丘、σ=0.10 なら8シード全部が高い丘）。10 は「変異の強さは
収束先を変えない」と書いたが、それは風景が単峰の場合の話だった。

### 筋5 — 揺らぎは局所最適から抜ける機会を作る。ただし両刃

置き直した前提はこう。

> **繁栄にはある程度の安定が必須で、その上で許容できる範囲の揺らぎが必要になる。**

希少な変異体は平衡状態では既存種の壁を越えられないが、既存種が谷に落ちた瞬間なら
食い込める。安定した平衡は、**居座っている側にとって最も守りが固い状態**でもある。

| 測ったこと | 結果 |
|---|---|
| 侵入（[12](reports/12-invasion.md)） | 揺らぎは不利な系統の通過率を**4倍**にする（山3.1% → 谷12.6%）|
| 非選択性 | 谷が足す量は有利さによらず 9〜11pp で一定。**有利な変異体しか通さない仕組みでは今いる丘を登ることしかできない**ので、非選択性は欠陥ではなく要件 |
| 脱出（[13](reports/13-escape.md)） | 41件の離脱のうち、個体数が上位25%の時期に起きたものは**0件** |
| 効いているのは谷（13） | 捕食者の頭数を揃えても谷は効き、谷を揃えると捕食圧は消える。**捕食圧は谷の逆数を見ていただけ** |
| もう一方の刃（[14](reports/14-mass-death.md)） | 侵入者を巻き添えから外すと定着率が上がる。**同じ谷の深さで比べても差が残る**（25% 対 18%）ので、これは「窓が開く頻度」ではなく「開いた窓で生き残れるか」の差 |

機構の見立ては「谷では1個体あたりの草が増えるので、**代償の高い形質が一時的に安くなる**」
（足に頼る型の実効代謝が 0.367 → 0.618 でほぼ倍）。
**ただしこれは解釈で、離脱時の1個体あたりの草はまだ測っていない。**

### 筋6 — 共存を作るのは死の量ではなく死の向き

筋2の「横の共存は自力で立たない」を裏返した側。3段構えで測った。

| | 操作 | 結果 |
|---|---|---|
| [15](reports/15-frequency-dependence.md) | 均等に減らす | **共存しない。** 除去率12倍・塊16倍に振っても全滅。動くのは絶滅の時刻だけ |
| [16](reports/16-crowding.md) | 自種の密度に比例して叩く（手書き） | **共存する**（8/8）。ただし共存条件を式で置いただけ |
| [17](reports/17-infection.md) | 接触で伝わる感染症 | **共存する**（8/8）。種の個体数はコードに出てこない |

**対照が2回とも同じ形で効いた。** 16 の「誰の密度を見るか」と 17 の「誰に移るか」は
どちらも機構もつまみも同一で、片方の性質だけが違う。そして
**どちらも対照のほうが多く殺しているのに共存しない**（17 の tr=1.0 で
1.39%/歩 対 0.95%/歩）。

そして 17 の実体は予想と違った。「増えた種ほど叩かれる」ではなく
「**少ない種が病気から逃げ切る**」。病原体の維持には宿主密度の下限があるので、
多いほう（A）だけが感染率45%で病気を抱え、少ないほう（B）は2〜6%で済む。
効果の向きは同じだが、連続的な調整ではなく**閾値**として働いている。

毒性にも内点の山が出た（致死性 0.02）。弱すぎると蔓延しても打撃が足りず、
強すぎると宿主を殺すのが早すぎて病原体が維持できない。
この釣り合いを手で書いた覚えは無い。

**そして 17 が要求した伝染確率0.8は、病気の強さではなく遭遇の少なさだった**
（[18](reports/18-density-threshold.md)）。密度を 0.12 → 0.48個体/セル に上げると
**伝染確率0.1で足りる**。閾値 × 密度がほぼ一定なので、必要なのは R0 であって
病原体の強さではない。共存する条件でAに届く打撃はどの密度でも 0.85〜0.95%/歩 で揃う。

これは筋3の「手が届く範囲」と同じ話。**この模型の低密度は、接触に依存する機構
すべての足を引っ張っている。**

## 4. 一番痛い教訓 — 動かした覚えのない軸が動く

覆った結論5件のうち3件がこれ。**新しい軸を足すときは、それが何を一緒に動かすかを
数える手段も一緒に作る。**

| 軸 | 狙い | 一緒に動いたもの | どうしたか |
|---|---|---|---|
| 死骸の還元（08） | 循環を閉じる | **総エネルギー入力**（＝豊穣化） | `grassAdded` と `grassFromCorpses` を分けて数えて発覚 |
| デトリタス在庫（09） | 流入のばらつきだけ下げる | 総入力も同時に動く | 分離できず、結論を出さなかった |
| 捕食まわりのつまみ（13） | 揺らぎだけ動かす | 速度の丘の位置 | 分離を諦め、**同じ走行の中の谷と山**を対照にした |
| 大量死・全種（14） | 形質を見ないので丘は動かないはず | 捕食者も減る → 捕食圧が下がる → 丘が 2.70 → 2.25 | 対象を**草食だけ**に絞ると成立する |
| 大量死・強め（14） | 同上 | 草食が谷に落ちれば捕食者も餓死する | **中程度まで**なら使える |
| 地形・全種（20） | 速度の代償だけ不均質にする | 捕食者も安くなる → 捕食圧が上がる → 丘が 2.74 → 2.94 | 14と同じく**草食だけ**に絞ると丘は動かない（2.77） |
| 地形の正規化（20） | 倍率の平均を1にしたので総量は固定 | 個体が安いセルに溜まり、**実際に払う平均は0.95まで落ちる** | 計測器を先に作ってあったのでその場で気づけた |

08の「回復速度をいじっていないのだからエネルギー量は同じはず」と、
14の「形質を見ていないのだから丘は動かないはず」と、
20の「倍率の平均を1にしたのだから総量は同じはず」は**全部同じ形の間違い**。
**3回踏んでいる。**

そして20は14の再演でもある——全種に掛けると捕食者経由で丘が動く、まで含めて同じ。
**過去の失敗を読んでいても、形が同じであることは事前には見えない。**

### 指標そのものが嘘をつくパターン

| やったこと | 何が起きたか | 正しい見方 |
|---|---|---|
| 平均を見た | 絶滅は平均では予測できない | **谷を見る**。表には必ず `平均(最小-最大)` |
| 3シードで判断（04） | 非単調な機構を「発見」しかけ、8シードで消えた | **既定は8シード**。`7/8` と `8/8` の差は読み分けない |
| 崩壊した試行を混ぜた（09） | 崩壊すると変動係数が跳ね上がる。**「高いから崩壊した」ではなく「崩壊したから高い」** | 崩壊後のデータを混ぜない |
| 変動係数で揺らぎを代弁した（14） | 0.494 対 0.534 とほぼ同じなのに、谷の深さは 0.20 対 0.04 で5倍違う | 定着率が追随するのは**谷の深さ**のほう |
| 周期のある系で相関を読んだ（08） | ラグを振ったら**符号が反転し続けた**。相関は周期を写していただけ | 相関を機構の証拠にしない |
| 比を平均した（13） | 分母が谷で小さくなる量の平均は、谷の深さに支配される。結論の向きが逆になった | 比の平均を取らない |
| 短い走行の生存率で安全と判断（14） | 崩壊確率は走行が長いほど積み上がる。8000歩で `8/8` が90000歩で `2/8` | **使う予定の長さで確かめる** |
| 部分集団の平均だけ見た（20） | 地形クラス別に平均しか出さず、「山に居着いた少数派」を原理的に見られなかった。逆に集団全体のばらつきの上昇（0.25→0.40）は分化に見えたが、割ると全クラス一様だった | **分けた先でも分布を見る。** 平均だけでは1点に集まっているのか割れているのかが区別できないのは、集団全体でも部分集団でも同じ |
| 要約が筋に寄った（[21](reports/21-r-star.md)） | 筋2の根拠3つのうち**2つが要約の段階で意味を変えていた**。05本文の「0.025〜0.045 の全域で 8/8 と頑健」が「共存はナイフエッジ」に、07本文の「共存自体は保たれる（8/8）」が「共存がさらに壊れた」に。3回とも同じ向き | **筋を書くと、筋に合う方向へ数字の読みが寄る。** 06 で知識が確認を省かせたのと同じ構造で、そこでは知識が、ここでは自分が書いた筋が働いた。要約を根拠に使う前に元のレポートを読み直す |

そして [03](reports/03-vision-and-pursuit.md) で3回。
走査順のバイアスが「群れて非効率になる」に、インデックス構築のタイミングが
「視野があると捕食者が不利になる」に見えた。どれも生態学的にありえそうな話だった。
**新しい挙動が出たら、まず実装を疑う。**

**4回目が [24](reports/24-quantize-check.md)。** 22 の高い丘に出た分布の凹凸は
「整数付近で分断選択が起きている」と読めたが、正体は走査半径の量子化だった。
端数を持つ個体は2つの半径を混ぜ、走査面積 (2r+1)² が半径に凸なので**混ぜ得**になる。
対競争で半整数が整数に4戦4勝し、帯に閉じ込めると両端から内点に収束する。
**適応度に刻み幅1の周期構造ができていた。**

皮肉なことに、これは 22 が「切り捨てにすると格子の刻み方だけで視野0に着く」を
避けるために入れた対策の側にあった。**切り捨てなら整数が山、確率繰り上げなら
半整数が山。向きが逆なだけで、どちらも格子が決めている。**

### 疑いが外れることもある — 5回目にはならなかった

[25](reports/25-low-hill-check.md)。24 の帯試験は 2.05-2.95 と 3.05-3.95 しか
踏んでおらず、**低い丘（0.80）も 22 節6 の勝者（0.79）も未検査の帯[0,1)に居た**。
24 が「22 の共存崩壊は視野0と3の比較で整数どうしだから安全」と書いたのは
**初期値**の話で、勝った側は端数だった。同じ形の5回目に見えた。

**外れた。** 帯[0.05,0.95]に閉じ込めると両端から **0.81**。混ぜ得は
`G(f)=4f(1-f)` で頂点が f=0.5 なので、格子だけなら 0.5 未満に来るはずだった。
24 の指紋（整数をまたぐときだけ一方的）も出ない——またがない 0.60対0.80 が
完全排除になる。**低い丘は生態が決めている。**

ただし**逆側に本物があった**。σ=0.01・捕食者ありでは高い丘が **3.36** に着く。
24 が帯[3.05,3.95]の内点として出した **3.37** で、刻みが小さいと整数を越えられず
帯に閉じ込められる。**低い丘の位置は生態が、高い丘の位置は σ を通じて格子が決めている。**

> 予測が反証されたこと自体は損ではない。**測る前に予測を書いていたから
> 反証だと分かった**——混ぜ得なら 0.5 未満、という一行が無ければ
> 「0.81 に来たから格子ではない」とは言えなかった。

## 5. まだ測れていないこと

結論として書けていない穴。ここを埋めないまま先へ進むと、後で同じ場所に戻ってくる。

- **揺らぎの量に対する応答の形。** [DIRECTION の予想表](DIRECTION.md#予想表)
  （小＝通らない / 中＝通る / 大＝殺される）のうち、14 で検定できたのは**前半だけ**。
  後半で定着率が折り返す点は無く、代わりに**世界のほうが先に消える**
  （900歩×90% で8シード中7〜8が崩壊）。
  「大きすぎる揺らぎは変異体を殺す」の前に「大きすぎる揺らぎは系を殺す」が来る
- **脱出の成功率。** 13 が数えたのは離脱で、着地ではない。
  利得22では19件が離脱して、高い丘に着いたのは2件しかない
- **谷で何が起きているかの直接の証拠。** 離脱時の1個体あたりの草は未測定
- **通した先に別の進化を歩めるか。** 12 の侵入者は固定の遺伝子型で、
  代謝という軸に第二の丘が無い。不利な侵入者が40/40消えたのは反証ではなく設定の帰結
- **代謝の変異。** 10 は速度でやった。単調な坂に崖が付いた軸なので、
  内点で釣り合う速度とは別の形が出るはず
- **同一種内の形質の分布に効く自己抑制。** 22 で、規則の違いは変異から出ず、
  すでにある違いも変異の下で消えることが分かった。17 の病原体は種を単位に
  しているので同一種内の分布には届かない。**形質が似ているほど移りやすい**形が
  要るが、それは形質空間での自己抑制を手で書くのに近い（16 が種の空間でやったこと）。
  **[25](reports/25-low-hill-check.md) が的を絞った**——必要なのは軸の上を
  動けなくすることではなく、**着地点を 0.81 から 0.5 あたりより下へ動かす**こと
- **共存の窓の端。** 25 は 0.50 で共存、0.80 で排除まで出した。
  **境界は詰めていない**（0.60・0.70 が未測定）。端が 0.55 なのか 0.78 なのかで、
  上の「0.3 ほど下へ」の値札が変わる
- **谷底の位置。** 25 は対競争で丘0.8-0.9 / 谷1.0-1.4 / 上り1.4以上まで出したが、
  1.0対1.2・1.2対1.4 を走らせていない

### 検討して「やらない」と決めたもの

- **個体へのバッファ（休眠・寿命延長）** — 生きている間はそれ自体がバッファとして
  機能している。軸を増やすと揺らぎとバッファの効果が混ざる
- **種ごとの応答の差を手で作る** — 変異システムの中で自然に出るべきもの

## 6. 次の一手

負の頻度依存（kill-the-winner）は[17](reports/17-infection.md) で入った（筋6）。
そこから残っているのは2本。

**A. 揺らぎのつまみとして使えるか — 測った。使えない**
（[19](reports/19-infection-as-noise.md)）。丘は動かないが揺らぎも作れない。
谷の深さは対照と差が無く（0.741 対 0.762）、効いていたのは**削り方**だった——
同じ除去率でも100歩にまとめると 0.350 まで落ちる。
**丘を動かさない理由と揺らぎを作れない理由が同じ**で、どちらも連続的で穏やかだから。
つまみを作るなら、まとめて叩く仕組み（潜伏期間・獲得免疫）が要る。

**B. 二つの丘を共存させる。** 筋4が終わった場所。17 の病原体は種を単位にしているので
目型と足型を区別しない。「形質が似ているほど移りやすい」形にすれば届くが、
それは形質空間での自己抑制を手で書くのに近い（16 が種の空間でやったことと同じ）。
先に 17 のままで測って、何も起きないことを確かめてからのほうがいい。

**[25](reports/25-low-hill-check.md) がこの的を絞り直した。** 22 は
「軸の上に留まれない」で終わっていたが、留まれる範囲は実在する
（無警戒型が 0.50 までなら相互侵入が両方向で通る）。壊しているのは
**1種を進化させた着地点が 0.81 で、その窓の外にある**こと。

だから B は「軸の上を動けなくする」ではなく「**着地点を 0.3 ほど下へ動かす**」に
なる。手で書かずにそれをやる仕組みが要る点は変わらない。

どちらも第4節がそのまま効く。**「それが何を一緒に動かすか」を数える手段を
先に作る**こと。17 では感染経路を接触と自然発生に分けて数える仕組みを機構と
同時に入れたので、「自然発生が主なら密度依存になっていない」をその場で確かめられた。

**C. ニッチ軸そのものを増やした。軸は2本になったが、汎用型が畳んだ**
（[23](reports/23-two-resources.md)）。07が資源の分布、[20](reports/20-terrain.md) が
代償の分布で塞がったので、資源そのものを2本にした。

**20 の壁（空間の均し）は迂回できた。** 専門型2種は供給比どおりに共存する
（A供給0.3で 469 : 1135、0.7で 1135 : 469、摂取は A100%/A0%）。
**別の壁に当たった**——汎用型を**30体**入れるだけで専門型が8/8で絶滅する。
`p=0.90`（10%崩しただけ）でも勝ち、その摂取内訳は A50%。

原因は配分の上限が一度も効かないこと。標準現存量は資源あたり約0.26、採食量は4。
**この模型の採食は遭遇律速で、戦略に対して線形**なので、何を食べるかを
配分しても損が出ない。21 が「食べる能力は効いていない」と既に書いていた。

### 22 と 23 は同じ壊れ方をした

| | 22（視野の軸） | 23（資源の軸） |
|---|---|---|
| 軸は実在するか | する（丘が2つ） | する（専門型2種が供給比どおり共存） |
| 中間型 | 両方の資源を取る | 両方の資源を取る |
| 結果 | 6000歩で片方が絶滅 | 8/8 で両方が絶滅 |
| 残った側 | 1種を進化させた場合と一致 | 資源1本の場合と一致 |

**2本続けて、軸を作ることには成功して、軸の上に2つの型が留まることに失敗した。**
共存が保たれるには**中間型が両端の平均より悪くなる**必要がある（凹なトレードオフ）。
次の選択肢は [DIRECTION](DIRECTION.md) に3つ挙げてある（未決）。

その先の候補は [DIRECTION](DIRECTION.md) の末尾に列挙してある
（捕食以外の種間関係、分解者を種として実装する、代謝の変異）。
