# 18 密度 — 伝染確率0.8が要ったのは病気の強さではなく遭遇の少なさ

[17](17-infection.md) は接触感染で共存を作れたが、伝染確率 0.8 を要求した。
「同じセルの感染者に接触したら8割移る」は病気として強すぎる。

**遭遇不足だった。** 草の回復速度を4倍にして密度を 0.12 → 0.48個体/セル に上げると、
**伝染確率 0.1 で共存する**（A 3977 / B 208、8シードすべて）。
病原体を強くする必要は無く、出会う機会が足りていなかっただけ。

[09](09-detritus-buffer.md) の「盤面に餌があっても大半の個体から手が届かない」と
同じ形。この模型の低密度（0.12個体/セル）は、**接触に依存する機構すべての
足を引っ張っている**。

- 実行: `node docs/reports/scripts/18-density-threshold.ts`（4スレッドで4分31秒）
- 条件: 8000ステップ / 後半4000ステップで統計 / 8シード。最後の節だけ30000ステップ

## 設計: なぜ回復速度なのか

平衡個体数が `回復速度 × セル数 ÷ 実効代謝` なので、密度は

```
密度 = 回復速度 ÷ 実効代謝
```

**セル数が消える。** 盤面を狭くしても個体数が一緒に減るので、密度は動かない。
動かせるのは回復速度と代謝の2つだけ。

**代謝は使えない。** A(0.5) と B(0.62) の差がそのまま A が B に勝つ理由なので、
下げると密度と競争の非対称性が同時に動く。[09](09-detritus-buffer.md) の在庫
（放出率）で「下げると変動係数も総入力も同時に動いて何も結論できなかった」のと
同じ形になる。

**回復速度は種のパラメータを1つも触らない。** A と B の関係を保ったまま
両方の密度が上がる。

## 節1 対照 — 餌を増やしただけでは共存しない

餌が増えれば競争が緩んで B が助かる、という筋がありうる。ニッチ軸が1本なので
理屈では助からないが、[06](06-enrichment.md) で豊穣化を読み違えているので測った。

| 回復速度 | 密度 | 生存 | 草食A | 草食B | Bの絶滅（中央） |
|---|---|---|---|---|---|
| 0.06 | 0.12 | -- 0/8 | 1298 (1231-1374) | **0** | 643 (479-756) |
| 0.12 | 0.24 | -- 0/8 | 2595 (2521-2664) | **0** | 609 (538-863) |
| 0.24 | 0.48 | -- 0/8 | 5188 (5107-5270) | **0** | 647 (545-963) |

**どの密度でも全滅。** 絶滅の時刻もほとんど動かない（643 / 609 / 647）。
餌の量は競争排除に対して何もしていない。以降の共存は感染のおかげだと言える。

回復0.06 の行は 15〜17 の節1と完全に一致。

## 閾値 × 密度はほぼ一定。ただし高密度側でさらに下がる

刻みが粗いので、閾値は区間でしか言えない。

| 密度 | 閾値の区間 | 閾値 × 密度 |
|---|---|---|
| 0.12 | (0.4, 0.6] | (0.048, 0.072] |
| 0.24 | (0.2, 0.3] | (0.048, 0.072] |
| 0.48 | (0.05, 0.1] | **(0.024, 0.048]** |

**密度 0.12 と 0.24 は区間が完全に一致する。** 遭遇率が密度に比例し、
R0 が 伝染確率 × 遭遇率 で決まる、という読みがそのまま当たっている。

密度 0.48 だけは区間が下にずれる。**予想より病原体が効きやすい。**
1/密度 で説明できるより、さらに閾値が低い。

理由は測っていない。有力なのは**Bの絶対数**で、密度0.48では共存点の B が
1424体まで増える。R0 とは別に、少数派が偶然消える確率そのものが下がっている
（[04](04-metabolism-stability.md) 以来の「桁が小さいと偶然だけで消える」の裏返し）。
閾値が下がった理由が感染の効きやすさなのか B の消えにくさなのかは、
この実験では分けられない。

## 強すぎる病気はBも叩き始める

密度0.24 の列に山がある。

| transmit | 草食B | Bの感染率 |
|---|---|---|
| 0.3 | 602 | 2% |
| **0.4** | **830** | 7% |
| 0.6 | 743 | **28%** |

Bが最も増えるのは 0.4 で、0.6 では減る。**Bの感染率が 7% → 28% に上がる**ので、
病原体がBにも定着し始めている。[17](17-infection.md) の「少ない種は病気から
逃げ切る」が、強い病原体では成り立たなくなる。

[14](14-mass-death.md) の両刃と同じ形。**窓を開ける効果と、少数派を巻き添えに
する効果**があって、強さを上げると後者が先に効いてくる。

## 外した見立て

**「回復速度を上げると振動が激しくなる」** — 外れた。振れ幅はむしろ相対的に
狭くなっている（±5% → ±3%）。

[04](04-metabolism-stability.md)・[06](06-enrichment.md) の「上限が上がるぶん
跳ね上がりが大きくなる」を持ち込んだが、**あちらは捕食者がいる構成の話**だった。
振動を作っているのは捕食者と被食者の結合で、この実験は肉食を外しているので
振動する仕組みが最初から無い。餌の量だけを上げた単独の集団は、
高い平衡に静かに張り付く。

知っている現象を、成り立つ条件を確かめずに当てはめた。
[06](06-enrichment.md) で豊穣化のパラドックスをやったのと同じ間違い方をしている。

## 測っていないこと

- **密度0.48で閾値が予想より下がった理由。** 感染が効きやすくなったのか、
  Bが偶然消えにくくなったのか。密度を上げると両方が同時に動く。
  分けるには B の初期個体数だけを変える等の別の操作が要る
- **遭遇率そのもの。** 密度から見積もっているだけで、同セル遭遇の回数を
  直接数えてはいない。`infectedByContact` は成功した伝染しか数えていないので、
  「何回出会って何回移ったか」は分からない
- **もっと高い密度。** 0.48 で頭打ちになるのか、さらに下がるのかは見ていない。
  回復速度0.48 なら個体数が1万を超えるので実行時間が問題になる
- **捕食者がいる場合。** 全条件で肉食を外している。密度を上げると捕食者にとっては
  餌が増えるので、[06](06-enrichment.md) の豊穣化がそのまま効くはず
- **既定の構成を変えるべきかどうか。** この結果は「この模型の既定密度が低すぎる」
  とも読めるが、既定を動かすと 02 以来の全レポートの数字と比べられなくなる
