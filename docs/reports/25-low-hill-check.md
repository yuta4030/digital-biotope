# 25. 低い丘は本物だった。そして共存の窓には幅があった

[22](22-vision-evolution.md) の看板は2つある。低い丘（約0.80）と、
「21 の共存構成に変異を入れると片方が絶滅する」（節6）。
どちらにも確かめていない前提が1つずつ残っていた。

- **低い丘は格子ではなく生態が決めている。** 帯[0.05,0.95]に閉じ込めると
  両端から **0.81** に来る。混ぜ得だけなら 0.5 未満に来るはずで、**予測は反証された**
- **[24](24-quantize-check.md) の指紋はこの帯に出ない。** 24 は
  「整数をまたぐときだけ一方的」を格子の証拠にしたが、ここでは
  **0.60 対 0.80（またがない）が完全排除**になる。勾配が桁違いに急
- **共存の窓には幅がある。** 無警戒型を 0.25 や 0.50 に置いても共存は残り、
  **相互侵入が両方向で通る**。専門型の取り分が **31% → 17% → 5% → 0** と
  連続的に削られる。22 は終点（0.79）しか見ていなかった
- **そして進化の着地点（0.81）は窓の外にある。** 22 の「軸の上に留まれない」は
  「どこにも留まれない」ではなく「**留まれる範囲はあるが、進化はその外へ行く**」
- **σ は閾値ではなく速度。** σ=0.01 は6000歩で共存に見えて（381体）
  30000歩で1体。全σで 22 の結論は保つが、**6000歩だけなら誤報していた**
- 副産物: σ=0.01・捕食者ありで警戒型が **3.36** に着く。
  24 が帯[3.05,3.95]の内点として出した **3.37**。
  **高い丘の位置のほうは、σ を通じて格子が決めている**

## なぜ測ったか

24 は 22 の高い丘に出た凹凸を量子化の副作用だと突き止め、
「22 の主要な結論は影響を受けない」と書いた。共存崩壊については
**「視野0と3の比較で、整数どうし」**が理由だった。

これは**初期値**の話で、**勝った側**の話ではない。節6 で勝ったのは **0.79** で、
端数を持つ。そして 24 の帯試験は 2.05-2.95 と 3.05-3.95 しか踏んでいない。
**低い丘も節6の勝者も、どちらも未検査の帯[0,1)に居る。**

もう1つ。節6 の表は**全行が σ=0.05** だが、同じレポートの節7 が
「**変異の刻みが行き先を決める**」（σ=0.05 なら低い丘、σ=0.10 なら8シード全部が
高い丘）を出している。刻みが結果を変えると自分で示した軸の、1点だけで
看板の結論を測っている。

### 予測を先に書いた

走査面積の混ぜ得は、混合の期待面積と「真の半径 v」の面積の差で、

```
G(f) = [(1-f)·1 + f·9] - (2f+1)² = 4f(1-f)      頂点は f=0.5
```

代償は連続値に線形にかかって下へ押す。だから**混ぜ得だけなら帯[0,1)の内点は
0.5 未満に来る**。22 が出したのは 0.78-0.80 で、予測より**上**にある。

つまりこの実験は、書く前から**自分の疑いに不利な向き**に予測が出ていた。

### 再現性

節5 を足して全体を再実行したところ、節1〜節4 は**同じ数字で再現**した。
シードから引き直しているので当然だが、確認はしてある。

## 節2: 対競争で風景の勾配を直接測る

個体数の平衡は生産÷実効代謝で決まるので適応度の代弁にならない
（24 が確立した測り方）。同じ世界に2つ入れて奪い合わせる。8シード / 6000歩。

| 対戦 | 結果 |
|---|---|
| 0.00 対 0.50 | 0 対 **902** |
| 0.50 対 0.80 | 0 対 **824** |
| 0.00 対 0.80 | 0 対 **828** |
| **0.80 対 1.00** | **839** 対 0 |

```
0.00 → 0.50 → 0.80 ← 1.00
```

**0.8 付近に頂上がある。** 0.8 は下からも上からも勝つ。

そして 24 の指紋——「同じ幅0.2でも整数をまたぐときだけ一方的」——が出ない。

| 対戦 | 整数をまたぐか | 結果 | 24 の対応する組 |
|---|---|---|---|
| 0.60 対 0.80 | またがない | **0 対 840** | 2.40対2.60 は拮抗（47%）|
| 0.90 対 1.10 | またぐ | **839 対 0** | 2.90対3.10 は完全排除 |
| 1.40 対 1.60 | またがない | 40 対 **815** | 3.40対3.60 は 814 対 7 |

**またがない 0.60対0.80 が完全排除になる。** 24 の帯2では同じ条件が拮抗だった。
この帯の勾配は格子の周期構造より桁違いに急で、22 節5 の
「**軸は坂ではなく崖で、崖は 0 と 1 の間にしかない**」がそのまま出ている。

### 混ぜ得では説明が要らない組が2つある

0.90 と 1.10 は混ぜ得が**同じ**（どちらも 0.36 セル。0.9 は半径0と1を、
1.1 は半径1と2を混ぜる）。だから純粋な代償比較になり、安いほうが勝つ。
**余計な説明が要らない。**

1.40 と 1.60 も混ぜ得が同じ（0.96 セル）。代償は 1.40 のほうが安いのに
**1.60 が勝つ**ので、ここでは利益の勾配が代償を上回っている。

```
丘 0.8-0.9   谷 1.0-1.4   上り 1.4以上 →（高い丘へ）
```

22 は進化の着地点から丘が2つあると推した。ここでは**勾配そのもの**が出ていて、
谷の存在が直接見える。

> 谷底の正確な位置は測っていない（1.0対1.2、1.2対1.4 を走らせていない）。
> 言えるのは「1.0 と 1.5 の間のどこか」まで。

## 何が言えるか

### 共存の窓には幅があり、進化の着地点はその外にある

22 は「軸があることと、その軸の上に2つの型が留まれることは別物」で終わった。
25 はその後半を分解する。

```
共存が成り立つ範囲   v ≦ 0.50（相互侵入で確認）… 0.80 では消える
1種を進化させた着地点 v = 0.81
```

**留まれる範囲は存在する。** ただし進化がそこへ行かない。
21 の共存が「軸の両端に固定されていること」に依存していた、という 22 の総括は
**きつすぎた**——両端である必要はなく、0.25 でも 0.50 でも共存する。
必要なのは**片方が 0.5 あたりより下に留まること**だった。

これは 22 の結論より扱いやすい形をしている。「軸の上を動けなくする」ではなく
「**着地点を 0.3 ほど下へ動かす**」で足りる。

### 次に何を測るか

- **境界を詰める。** 0.60 と 0.70 を節3・節5 と同じ形で。
  窓の端が 0.55 なのか 0.78 なのかで、上の「0.3 ほど」の値札が変わる
- **着地点を下げる圧力があるか。** 低い丘の位置（0.81）は
  採食の最適として決まっている（22 節5 の視野ビン別の歩あたり摂取が
  0.75-1.00 で最大）。これを下へ動かすものが要る。
  [筋6](../OVERVIEW.md#筋6--共存を作るのは死の量ではなく死の向き)の
  負の頻度依存が形質空間で効けば候補になるが、
  17 の病原体は種を単位にしているので届かない（22 が既に指摘済み）

### 測り方について

**規則7 が2回効いた。** 節4 の σ=0.01 は6000歩で共存に見え、
節3 の v=0.25/0.50 は30000歩でも動かないのに相互侵入を通すまで確定できなかった。
**同じ走行の中に「6000歩では嘘」と「30000歩でも足りない」の両方が出た。**

そして節3・節5 の設計が効いた理由は 23 と同じ形にある。
23 節4 は `p=0.90` の名目上の専門型を並べて「実は A50% を取っている」を暴いた。
**進化に任せず、中間の状態を手で置いて対照にする**と、機構と動態が分かれる。
