# 21. 共存はすでにあった — 視野の有無が2本目のニッチ軸になっている

[20](20-terrain.md) が「空間の不均質さ」の道を塞いだので、次はニッチ軸そのものを
増やすことになる。その設計の下ごしらえとして R\* を測った。**下ごしらえのほうが
本題より大きいものを出した。**

- **`upkeep` の草食2種は、捕食者なしで共存する。** 30000ステップ・8シード・
  相互侵入が両方向・どちらから始めても同じ平衡（478 : 1055）に収束する
- 機構も測れた。**同じ資源から同じ量のエネルギーを、違う取り方で取っている**——
  無警戒型は94%の歩で 0.423 ずつ、警戒型は46%の歩で 1.032 ずつ。歩あたりの摂取は
  両種とも実効代謝とビタ一致（比 1.00）
- **同じ採食規則の中でだけ R\* が勝敗を決める。** 規則が違うと R\* は 4.9倍
  離れていても共存する（2.577 対 0.528）
- パッチを入れると壊れる。ただし**30000ステップまで見えない**（6000歩で 8/8、
  30000歩で 3/8・5/8）
- **[OVERVIEW](../OVERVIEW.md) 筋2 の根拠3つのうち2つが、要約の段階で
  意味を変えていた。** 3回とも同じ向き——「共存しない」側へ

## R\* とは何か、なぜ測ったか

**その種が単独で資源をどこまで引き下げられるか、の水準。** 1種だけ置いて平衡させ、
残った草を見る。

要点は、**1本の資源をめぐる競争ではこの1つの数字で勝敗が決まる**こと。
A の R\* が 0.53、B が 0.89 なら、A は草を 0.53 まで削る。B は 0.89 より下では
減る種なので、0.53 の世界では増えられない。初期個体数がいくつでも消える。

だから共存の条件も1行になる。**資源が2本あって、種ごとに R\* の低い資源が違えばいい。**
互いに自分が強い側を自分で枯らすので、それが自己抑制になる。
[16](16-crowding.md) のように共存条件を式で置くのではなく、
[17](17-infection.md) と同じく機構から出る形。

資源を2本にする前に確かめたかったのは、**いまの1資源の模型で R\* が実際に
勝敗を予測するのか**。予測しないなら、2本にしても設計の根拠が無い。

### 予想

採食は `eaten = min(セルの草, gainFromGrass)` で、`gainFromGrass` は4、
標準現存量は約1。**個体はセルの草を丸ごと食べていて、食べる能力は効いていない。**
だとすると摂取を決めるのは遭遇だけなので、

```
標準現存量 ≒ 回復速度 ÷ 密度 、 密度 ≒ 回復速度 ÷ 実効代謝
→ R* ≒ 実効代謝
```

**半分当たって、半分外れた。** 同じ採食規則の中では当たる。規則が違うと壊れる。

## 節1: R\* は実効代謝と一致するか

単独で走らせ、平衡での草の残量を測る。8シード / 6000ステップ。

| | 実効代謝 | R\*（セルあたり） | R\*/実効代謝 | 個体数 |
|---|---|---|---|---|
| keystone A 代謝0.40 | 0.400 | 0.527 | 1.32 | 1622 |
| 〃 0.50 | 0.500 | 0.688 | 1.38 | 1298 |
| 〃 0.62 | 0.620 | 0.892 | 1.44 | 1047 |
| 〃 0.80 | 0.800 | 1.222 | 1.53 | 811 |
| upkeep 無警戒型（視野0） | 0.400 | 0.528 | 1.32 | 1622 |
| **upkeep 警戒型（視野3）** | 0.475 | **2.577** | **5.42** | 1357 |

視野0の種はすべて比が 1.32〜1.53 に収まる。無警戒型が keystone A の代謝0.40 と
ビタ一致する（0.528 対 0.527）のは、実効代謝も採食規則も同じだから。

**視野を持つと R\* が4.9倍に跳ね上がる。** 草を探して動くと豊かなセルを追いかけて
痩せたセルを刈り残すため。[07](07-grass-patches.md) が測った刈り残し
`2.54 対 0.53` と同じ数字で、**07 は R\* を測っていて、そう呼んでいなかった。**

> `grassMean` は草の**総量**で、セルあたりではない。最初これを読み違えて
> R\* を4桁の値として出した。`_lib.ts` のコメントも「セルあたり」と書いてあり、
> 直した。

## 節2・節3: R\* の低いほうが勝つか

| | 実効代謝 | 同居させると |
|---|---|---|
| keystone 草食A / 草食B | 0.500 / 0.620 | **A 1298(1231-1374) / B 0(0-0)** |
| upkeep 警戒型 / 無警戒型 | 0.475 / 0.400 | 警戒 480(414-551) / 無警戒 1052(965-1173) |

keystone は予想どおり排除。R\* が 0.688 対 0.892 で、低いほうが勝つ。
[02](02-preset-validation.md) の `A 1298 / B 0` と一致。

**upkeep は排除されない。** R\* が 2.577 対 0.528 で 4.9倍離れているのに、
高いほうが 480 体で安定している。

無警戒型の基礎代謝を上げて実効代謝を追い越させても、どこでも排除が起きない。

| 無警戒の実効代謝 | 警戒（0.475固定） | 無警戒 |
|---|---|---|
| 0.400 | 480(414-551) | 1052(965-1173) |
| 0.450 | 542(457-631) | 870(765-960) |
| **0.475（同点）** | 567(451-645) | 800(707-927) |
| 0.500 | 590(495-683) | 738(657-847) |
| 0.550 | 639(542-733) | 629(541-721) |

**1本の資源しか制限要因が無いなら、R\* が4.9倍高い種は存在できない。**
できているということは、制限要因が2つある。

## 節4・節5: 本当に共存か

R\* の破れを主張する前に、**遅い排除**を潰す必要がある。
[14](14-mass-death.md) が「8000ステップで 8/8 だった条件が90000ステップでは 2/8」を
踏んでいる。

| | 生存 | 警戒型 | 無警戒型 |
|---|---|---|---|
| 6000ステップ | 8/8 | 480(414-551) | 1052(965-1173) |
| 30000ステップ | **8/8** | 478(395-566) | 1055(946-1164) |

値が動かない。次に**相互侵入**——片方を5体から始めて増えるか。両方向で増えるなら
共存、片方向だけなら途中経過。

| 5体から始めた側 | 警戒型 | 無警戒型 |
|---|---|---|
| 警戒型 | **480**(394-575) | 1053(938-1157) |
| 無警戒型 | 478(401-562) | **1054**(947-1165) |

**両方向から侵入でき、どちらから始めても同じ平衡に戻る。** 8/8。
捕食者も感染も密度依存の死も無い。

同じ比に**両側から収束する**のは中立な共存（漂流）では起きない。内点の安定平衡がある。

## 節6・節7: 何が2本目の軸なのか

見立ては「**平均 対 上側の裾**」。無警戒型は草の平均に制限されるが、警戒型は
豊かなセルを選んで食べるので分布の上側に制限される。同じ資源でも制限されている
統計量が違うなら、制限要因は1つではない。

直接の証拠として、**1回の採食で取れた量**を種別に測る。

| | 1回の採食 | 世界平均比 |
|---|---|---|
| 世界平均（セルあたりの残量） | 0.518 | — |
| 警戒型 | **1.032** | 1.99 |
| 無警戒型 | 0.423 | 0.82 |

**2.4倍違う。**

> これは step の外からは測れない。最初はステップ後に個体のいるセルの草を見たが、
> 個体は自分のセルを食べ切るので**両種とも 0.000** になった。
> World に採食の計器（`grazeAmount` / `grazeCount`）を足してある。

### 予測が当たった

節6 の数字は「成功したときの量」で、歩あたりの摂取ではない
（`grazeCount` は草が0のセルを数えない）。平衡では死骸も捕食も無いので
**1個体あたりの摂取は実効代謝と釣り合う**はず。だとすると採食に成功する歩の割合は
`0.475/1.032 = 46%` と `0.400/0.423 = 95%` になる——という予測を先に書いて測った。

| | 実効代謝 | 歩あたりの摂取 | 比 | 採食頻度 | 1回あたり |
|---|---|---|---|---|---|
| 警戒型 | 0.475 | 0.474 | **1.00** | **46%** | 1.032 |
| 無警戒型 | 0.400 | 0.400 | **1.00** | **94%** | 0.423 |

予測 46%/95% に対して実測 46%/94%。摂取と実効代謝の比は両種とも 1.00。

> **無警戒型は94%の歩で 0.423 ずつ、警戒型は46%の歩で 1.032 ずつ食べる。
> 合計は同じで、制限しているものだけが違う。**

無警戒型を制限しているのは「草のあるセルの密度」、警戒型を制限しているのは
「濃いセルの密度」。**1本のスカラー場から、2つの制限要因が出ている。**

### なぜこれが面白いか

資源を2種類にして得意を逆にする案は、**トレードオフを種の定義に書き込む**。
世界の側に軸を2本用意して、種をそれに合わせて置く。

ここで起きているのは逆で、**草はスカラー1本、全セル一様に回復する。世界の側に
軸は1本しかない。** 標準現存量の空間的なばらつきは**採食そのものが作っている**——
さっき食べられたセルは空で、しばらく誰も来ていないセルは溜まっている。
回復は一様なので、ばらつきの出どころは訪問の履歴だけ。

**2本目の軸は世界の性質ではなく、消費者の集合が生成している統計量。**

## 節8: パッチは壊す。ただし30000ステップまで見えない

| | 6000歩 | 30000歩 |
|---|---|---|
| 強さ0 | 8/8 警戒型 480 | **8/8** 警戒型 478 |
| 強さ0.6 | 8/8 警戒型 **10**(4-25) | **3/8** 警戒型 2(0-10) |
| 強さ0.9 | 8/8 警戒型 **11**(4-25) | **5/8** 警戒型 2(0-8) |

絶滅は 14365〜27395歩 で起きている。**6000ステップでは見えない。**

（3/8 と 5/8 の差は読まない。どちらも「よく崩れる」）

### 見立て: 予測できる不均質は分割を壊す

一様な世界での濃いセルは、誰かが最近食べたかどうかだけで決まる——**散在していて、
その場限りで、次にどこへ出るか分からない**。だから視野持ちが集まりようがなく、
各個体に事実上私有の資源になる。

パッチを入れると、濃い場所が**予測可能で固定で共有**になる。全員が同じ的を狙う。
07 が書いた「草を探して動く個体は餌の多い場所に集まって競争を激化させ、
刈り残しも増える」がそれ。

> **不規則な不均質は分割を支え、規則的な不均質は分割を壊す。**

**ただしこれは見立てで、機構としては確かめていない。** 対抗する説明がある——
パッチを入れると無警戒型が 1052 → 1609 に増えており、そちらが草を押し下げて
警戒型を潰した可能性。どちらが効いているかは分けていない。

### 模型の側の穴

07 の崩壊は「視野持ちどうしが同じ場所に殺到する」で起きているが、
**この模型の視野は混み具合を見ていない**。周囲で草が最も多い方向へ行くだけなので、
全員が同じ判断をする。現実の丁寧な採食者は餌の多さと混み具合の両方を見て、
混んでいれば別の場所へ行く。

だから 07 の「視野は不均質で損」は、現実の反映というより**規則の穴の帰結**かもしれない。
[03](03-vision-and-pursuit.md) で3回踏んだ「実装の都合が生態系の挙動として
観察される」の形に見える。視野の評価を「草の量」から「草の量 ÷ そのセルの個体数」に
変えれば試せるが、規則を変えると 05・07・10・13 の前提が全部動くので、
既定にはできない。

## 文書の側で見つかったこと

[OVERVIEW 筋2](../OVERVIEW.md) は「横の共存は自力で立たない」と書いていて、
根拠を3つ挙げている。**2つが要約の段階で意味を変えていた。**

| 根拠 | OVERVIEW の書き方 | 元のレポート | 実際 |
|---|---|---|---|
| 競合 | A 1298 / B 0 | 同じ | **正しい** |
| 燃費（[05](05-activity-cost.md)） | 共存するのは視野コスト 0.025〜0.030 の**ナイフエッジ** | 「交差点付近は 0.025〜0.045 の全域で 8/8 と**頑健**」（05本文） | **要約が誤り。** 共存は頑健で、ナイフエッジなのは*どちらが多いか* |
| パッチ（[07](07-grass-patches.md)） | 不均質にすると**共存がさらに壊れた** | 「勝敗がひっくり返るだけで**共存自体は保たれる（8/8）**」（07本文） | **どちらも不十分。** 30000歩では実際に壊れる（3/8・5/8）が、07 のデータはそれを示していなかった |

3回とも同じ向き——「共存しない」側へ。**個々のレポートのほうが正確だった**（05）か、
**要約が結論としては当たっていたが根拠は無かった**（07）。

これは [OVERVIEW §4](../OVERVIEW.md#4-一番痛い教訓--動かした覚えのない軸が動く) が
測定について言っていることの、**要約についての版**だと思う。
筋を書くと、筋に合う方向へ数字の読みが寄る。
[06](06-enrichment.md) で「豊穣化のパラドックス」を知っていたせいで確認を省いたのと
構造が同じで、そこでは知識が、ここでは自分が書いた筋が、確認を省かせている。

## 何が言えるか

### 共存を作った機構は3つになった

| | 何が共存を作ったか | 手で書いたか | 出典 |
|---|---|---|---|
| [16](16-crowding.md) | 自種の密度に比例した死 | **書いた**（共存条件そのもの） | rate 0.1 以上で 8/8 |
| [17](17-infection.md) | 接触感染 | 書いていない | 伝染確率 0.8 以上で 8/8 |
| **05 / 21** | **視野の有無（採食規則の違い）** | 書いていない | 相互侵入で 8/8 |

そして**05 は 17 より前に出ていた**。誰も共存として数えていなかっただけで。

### 元の問いへの答えが一段変わる

> 多様性は突然変異とトライアンドエラーだけの仕組みで実現できるのか

「資源の種類を増やせば種が増える」は、世界を先に多様にしておく話で、問いをずらしている。
**行動規則の違いだけで軸が1本増えるなら、世界が事前に構造化されている必要がない。**

ただし**この模型では規則は遺伝しない**。`visionRange` は種の定数で、
[10](10-speed-evolution.md) が遺伝させたのは速度だけ。
「規則の違いが変異から出てくるか」はまだ何も測っていない。

### 20 との対比

[20](20-terrain.md) は環境に構造を**足した**。均された——消費者が再分布して
適応度を揃えてしまうため。こちらは消費者が構造を**作っている**。
そして均されない。構造を利用する行為そのものが構造を再生産しているので。

**ただしこれも見立て。** 一様な世界での共存は測定だが、
「作られた構造だから均されない」は説明であって、直接は測っていない。

## 外した見立ての一覧

| 書いたこと | 実際 |
|---|---|
| R\* ≒ 実効代謝 | **半分。** 同じ採食規則の中では成り立つ（比 1.32〜1.53）。視野を持つと 5.42 に跳ねる |
| 視野コストを振れば実効代謝の大小が入れ替わり勝敗も反転する | 反転する軸ではなかった（視野コスト>0 なら常に警戒型が高い）。基礎代謝で追い越させたが、**どこでも排除が起きなかった** |
| 資源を2本にするのが次の一手 | **その前にもう1本あった。** 下ごしらえのほうが本題より大きいものを出した |
| （当たり）2種は草の違う部分を食べている | 1回の採食で 1.032 対 0.423 |
| （当たり）採食頻度は 46% / 95% | 実測 46% / 94%。摂取と実効代謝の比は両種とも 1.00 |
| （当たり）パッチ下の 16体 は長く走らせると消える | 30000歩で 3/8・5/8。07 の 8/8 は走行の長さの産物だった |

**測定側でも1つ外している。** クラス別の草を測るのに、ステップ後に個体のいる
セルを見た。個体は自分のセルを食べ切るので両種とも 0.000 になる。
`step` の中に計器を置かないと測れない量だった。
