# 27. 両方が真ん中へ動く — 壁はどちらにも無かった

[26](26-position-or-gap.md) は「効いているのは低いほうの絶対位置」で終わった。
だがその実験は**高いほうをずっと3に置いていた**。高いほうも動かしてみたら、
結論が2つ変わった。

- **窓は両側にある。** 低いほうを0という一番安全な場所に固定しても、
  高いほうを **0.95 まで下げると低いほうが絶滅する**（1532 : 0）。
  26 の「効いているのは低いほうの絶対位置」は**不完全**だった
- **壁はどちらにも無い。** 高いほうだけを変異させると **1.0 で止まらず
  0.80 まで降り切り**、低いほうを絶滅させる。初期1.2 からも 1.5 からも同じ。
  **「多数派の規則に入るのが壁になる」という予測は外れた**
- **だから片方を押さえるだけでは足りない。** 25・26 の「着地点を 0.2 下げれば
  共存が保たれる」は**低いほうしか動かない前提**だった
- **両方が真ん中へ向かうのが直接見えた。** σ=0.01 の推移で
  高いほうが 3.00 → 2.80、低いほうが 0.12 → 0.61。
  **低いほうが 0.6 を越えた時点で高いほうが消える**（26 の境界と一致）
- 速いのは低いほう。σ=0.05 では 2500歩で 0.7 まで登る一方、
  高いほうは 3.00 → 2.89 しか動かない。**距離も勾配も低いほうが有利**
- **上の窓の端は 1.00 ちょうどに段差がある。** 1.10/1.05/1.00 で高いほう
  585/588/593 と平らなのに、**0.99 で 994 に跳ぶ**。
  ただし 0.99 でも共存はする（994 : 568）。崩壊は 0.95

> 節を1つ足して全体を再実行したところ、既存の節は**同じ数字で再現**した。

## 節1: 高いほうを 1.0 より下へ（静的）

26 は高いほうを 1.0 で止めていた。低いほうは視野0に固定・変異なし・8シード・30000歩。

| 低い側 | 高い側 | 高い側の個体数 | 低い側 |
|---|---|---|---|
| 0.00 | 1.00 | 593 (517-683) | **992** (889-1080) |
| 0.00 | **0.90** | 1535 (1483-1579) | **0** (0-0) |
| 0.00 | 0.81 | 1543 (1497-1584) | 0 (0-0) |
| 0.00 | 0.70 | 1553 (1512-1597) | 0 (0-0) |
| 0.00 | 0.60 | 1562 (1519-1596) | 0 (0-0) |

**低いほうを0に置いてあるのに絶滅する。**
26 が「低いほうが 0.55 より下なら共存」と書いた条件を満たしているのに壊れる。

**26 の規則は不完全だった。** 26 は高いほうを常に3に置いていたので、
高い側の条件が**一度も効いていなかった**。正しくは両側にある。

```
共存する条件   低い側 ≦ 0.55〜0.60   かつ   高い側 ≧ 0.95〜1.00
```

26 のデータもこれで全部説明がつく（低0.25/高1.00 は両方満たす、
低0.60/高3.00 は左を破る）。そして**「間隔は効かない」のほうは無傷**——
間隔0.75（低0.25/高1.00）は共存し、間隔0.90（低0/高0.90）は壊れる。
間隔では順序が説明できない。

## 節2: 崖は整数ちょうどにあるのか — 半分だけ晴れた

節1 の崖が 0.90 と 1.00 のちょうど間に出たので、実装を疑った
（[規則11](../../CLAUDE.md)）。`quantize` は `frac > 0 && rng.chance(frac)` なので、
**視野1.00 だけが乱数を引かず常に半径1**になる。0.99 は99%が半径1で1%が盲目。

| 高い側 | 高い側の個体数 | 低い側 | 高い側の取り分 |
|---|---|---|---|
| 1.10 | 585 (497-660) | 997 | 37% |
| 1.05 | 588 (504-698) | 996 | 37% |
| **1.00** | **593** (517-683) | 992 | **37%** |
| **0.99** | **994** (916-1075) | **568** (489-642) | **64%** |
| 0.95 | 1532 (1477-1584) | **0** | 100% |

**疑いは半分だけ晴れた。**

- **「端数があれば何でも壊れる」は外れ。** 0.99 でも共存する（994 : 568）。
  崩壊するのは 0.95。崖は 0.95 と 0.99 の間で、整数ちょうどではない
- **ただし 1.00 と 0.99 の間に段差がある。** 1.10 → 1.00 は 585 → 593 と
  ほぼ平ら（幅0.10で8体）なのに、**1.00 → 0.99 は 593 → 994**（幅0.01で401体）。
  多数派が入れ替わる

段差の位置は偶然ではない。**1.00 は「盲目の歩が1歩も無い」最後の値**で、
そこを割った瞬間に高いほうが低いほうの規則に足を踏み入れる。

### この段差は走査規則に依存している

**1.00 という位置そのものは、この模型の走査規則が決めている。**
[24](24-quantize-check.md) が挙げた選択肢3（走査を連続にする）を採ると、
最も近いセルまでの距離は1なので **v < 1 は全部まるごと盲目**になり、
[0,1) の帯という構造自体が消える。

つまり**上の窓の端（0.95〜1.00）は、24 が「細かい位置の議論は避けろ」と
書いた種類の主張**になる。下の端（0.55〜0.60）も同じ帯の中の話なので同様。

**粗い結論のほうは影響を受けない**——節3・節4 の「両方が真ん中へ動く」は
視野3から0.80 への移動で、整数を2つまたぐ。

> **段差の機構は測っていない。** 盲目の歩が1%混ざるだけで多数派が
> 入れ替わる理由は、armchair では出せない（[規則10](../../CLAUDE.md)）。
> 21 が使った採食の計器（`grazeAmount` / `grazeCount`）を種別に当てれば
> 「1%の盲目の歩が何を取っているか」が測れる。次の候補。

## 節3: 低いほうだけ変異させる

高いほうは視野3の定数。σ=0.05 / 8シード。

| | 高い側の視野 | 高い側 | 低い側の視野 | 低い側 |
|---|---|---|---|---|
| 6000歩 | 3.00 | 40 (0-352) | 0.70 (0.69-0.75) | 1508 |
| 30000歩 | —（絶滅） | **0** | **0.80** (0.80-0.80) | 1543 |

**低いほうだけで壊れる。** 22 節6 は両方に変異を入れていたので、
低いほうの上昇だけで十分だったことがここで確定した。

推移は 5000歩の時点ですでに 0.80 に着いていて、高いほうは既に消えている。
**σ=0.05 では速すぎて途中が見えない**（節5 の σ=0.01 で見る）。

## 節4: 高いほうだけ変異させる — 本題。予測は外れた

低いほうは視野0の定数。σ=0.05 / 8シード。

| | 高い側の視野 | 高い側 | 低い側 |
|---|---|---|---|
| 6000歩 | 2.91 (2.87-2.99) | 481 (389-558) | 1054（まだ共存）|
| 30000歩 | **0.80** (0.80-0.80) | 1543 | **0** |

推移（5000歩ごと。`高/低`、`--` は絶滅）:

```
seed 1000  2.79/0.00  2.38/0.00  1.83/0.00  0.80/ --   0.80/ --   0.81/ --
seed 2000  2.78/0.00  2.32/0.00  0.97/0.00  0.80/ --   0.81/ --   0.80/ --
seed 3000  2.84/0.00  2.44/0.00  2.12/0.00  1.85/0.00  0.80/ --   0.80/ --
```

**1.0 で止まらない。** 3 から一直線に降りて 0.80 に着き、低いほうを絶滅させる。

下から出発しても同じ（初期1.2 → 0.80、初期1.5 → 0.80）ので、
初期値に流されたのではなく **0.80 が着地点**。
22 節2 の「単独進化の着地点は 0.80」と**ビタ一致**する——
1000体の競争相手がいても行き先が変わらない。

### 予測が外れた

> 降りると相手（視野0・約1000体）の規則に入るので、1000体との競合が
> 自分に返ってくる。**壁がありうる。**

**壁は無かった。** 降りる途中で不利になる区間が存在しない。
節1 が理由を示している——高いほうが 0.95 まで降りた時点で低いほうが**消える**ので、
「1000体との競合」はそもそも発生しない。**降りる側が先に相手を殺してしまう。**

## 節5: 両方変異 — 両方が真ん中へ向かうのが見えた

σ=0.05 では速すぎる（2500歩で決着）。**σ=0.01 の推移が本題。**

```
高/低、5000歩ごと
seed 1000  3.00/0.12  2.99/0.26  2.96/0.42  2.89/0.52  2.80/0.61   -- /0.70
seed 2000  3.01/0.12  3.03/0.29  3.03/0.46  3.04/0.58   -- /0.70   -- /0.76
seed 3000  3.00/0.12  2.99/0.26  2.96/0.37  2.94/0.50  2.85/0.64   -- /0.74
seed 6000  2.98/0.12  2.99/0.27  2.92/0.40  2.86/0.50  2.80/0.63   -- /0.72
```

**両方が動いている。** 高いほうは 3.00 → 2.80、低いほうは 0.12 → 0.70。
向きは互いに近づく側。

そして**高いほうが消えるのは、低いほうが 0.6 を越えた直後**。
seed 1000 は 25000歩で低0.61・高2.80 が生きていて、30000歩で高が消える。
seed 2000 は 20000歩で低0.58、25000歩で消える。
**26 が静的に測った境界 0.55〜0.60 が、動的にもそのまま出た。**

### 速いのは低いほう

同じ 25000歩で低いほうは 0.49 動き、高いほうは 0.20 しか動かない。
壊すのに必要な距離も低いほうが短い（0 → 0.55 の 0.55 に対して、
高いほうは 3.0 → 0.95 の 2.05）。**距離も速度も低いほうが有利**なので、
両方に変異があれば低いほうが先に壊す。

これで 22 節6 の読みが説明できる。22 は「動いたのは無警戒型だけで
警戒型はほぼその場（3.00 → 2.92）」と書いたが、**警戒型は
「動かない」のではなく「遅い」**だけだった。σ=0.01 まで落とすと下りが見える。

| σ | 6000歩の高い側 | 30000歩の高い側 |
|---|---|---|
| 0.05 | 2.96、47体 | 絶滅 |
| 0.01 | — | 2.80、1体 |

## 26 と 25 のどこを直すか

| これまでの書き方 | 27 の後 |
|---|---|
| 効いているのは低いほうの絶対位置（26）| **不完全。両側にある**（低 ≦ 0.55〜0.60 かつ 高 ≧ 0.95〜1.00）。26 は高いほうを3に固定していたので右側が効いていなかった |
| 間隔は効かない（26）| **保つ。**間隔0.75 は共存し、間隔0.90 は壊れる |
| 着地点を 0.2 ほど下げれば共存が保たれる（25・26）| **足りない。**低いほうを0に固定しても高いほうが降りて壊す（節4）。**両側を押さえる必要がある** |
| 警戒型はほぼ動かない（22 節6）| **遅いだけ。**σ=0.01 で 3.00 → 2.80 と下っている |
| 軸は「見るか見ないか」のほぼ二値（26）| **強まる。**両方の境界が 0 と 1 の間の崖をまたいでいる |

## 外した見立て

| 見立て | 実際 |
|---|---|
| **高いほうには壁がある**（降りると多数派の規則に入るので不利になる）| **外れ。**1.0 を素通りして 0.80 まで降りる。降りる側が先に相手を殺すので競合が発生しない |
| 壁が片側にしか無いことが非対称の正体 | **外れ。壁はどちらにも無い。**非対称なのは壁ではなく**速度と距離** |
| 崖は整数ちょうどかもしれない（端数があれば何でも壊れる）| **半分外れ。**0.99 は共存する（崩壊は0.95）。ただし 1.00 と 0.99 の間に段差はある |
| （当たり）両方が境界へ向かっている | σ=0.01 で 3.00 → 2.80 と 0.12 → 0.70 |
| （当たり）低いほうだけで壊れる | 30000歩で高いほうが絶滅 |

**1つ目と2つ目は同じ見立ての表と裏で、両方外れた。**
しかも外れ方が「予測より悪い」方向だった——壁が片側にあれば
片側を押さえるだけで済んだが、無いなら両側が要る。

## 何が言えるか

### 共存の配置は、両端から内側へ崩れる

```
       ← 高いほうが降りる
0 ──────┬───── 0.8 ─────┬────────── 3
    0.55│              │0.95
        └─ 共存が壊れる ─┘
   低いほうが登る →
```

**0.80 は誰に対しても勝つ場所。**
[25](25-low-hill-check.md) 節2 の対競争が既にそう出していた
（`0.0 < 0.5 < 0.8`、かつ 0.8 は 1.0 にも勝つ）。共存はその両側に
1つずつ留まってもらう配置で、**留める力が働いていない。**

だから 22 の「軸の上に留まれない」は、25・26 で一度
「留まれる範囲はある」に緩んだあと、27 で**もう一段きつく戻った**。
範囲はある。だが**両端とも内側へ落ちる**ので、範囲があること自体が
助けにならない。

### 必要な仕組みの条件が1つ増えた

25 は「着地点を窓の中へ戻す」と書いた。27 の後はこうなる。

> **真ん中（0.6〜0.95）にいることを個体として損にする。**
> 片側だけ止めても、もう片方が降りてくる。

これは「両端を守る」と同じことで、[筋6](../OVERVIEW.md#筋6--共存を作るのは死の量ではなく死の向き)の
負の頻度依存が形質空間で効けば自然に満たす形をしている——
中間型は両方の資源を取るぶん、どちらの側から見ても「多いほう」に見える。
**ただしそれは見立てで、17 の病原体は種を単位にしているので届かない。**

### 次に測るもの

- **1.00 の段差の機構。** 盲目の歩が1%混ざるだけで多数派が入れ替わる
  （593 → 994）。21 の採食の計器を種別に当てれば「1%の盲目の歩が
  何を取っているか」が出る。**節2 の位置の議論が走査規則に依存している以上、
  ここは機構が分からないと引用しにくい**
- **両方を押さえる仕組み。** 上の条件を満たす機構の候補を1つ選んで試す
- **速度差の一般性。** 低いほうが速いのは「崖が 0 と 1 の間にある」ためで、
  この軸に固有かもしれない。速度（[10](10-speed-evolution.md)）でも
  同じ非対称が出るかは測っていない

### 測り方について

**片側を固定した実験は、固定した側の条件を見えなくする。**
26 は高いほうを3に置いて「効いているのは低いほうだ」と結論した。
27 は同じ形の誤りを避けるために逆側も動かし、両側に条件があると分かった。

25 → 26 → 27 で**3回続けて、前の回が固定していた軸を動かすと結論が変わっている**。
[OVERVIEW §4](../OVERVIEW.md#4-一番痛い教訓--動かした覚えのない軸が動く) は
「動かした覚えのない軸が動く」を挙げているが、こちらは逆で
**「動かさなかった軸が結論を作っていた」**。同じ表の別の列として記録しておく。
