# 26. 軸は「見るか見ないか」だった — 2種の間隔は効いていない

[25](25-low-hill-check.md) 節3 は高い側を視野3に固定して低い側だけを振ったので、
**「低いほうの絶対位置」と「2種の間隔」が同時に動いていた**。境界を説明する規則が
2つあり、25 のデータはどちらとも整合していた。

- **間隔は効いていない。** 低い側を0に固定して高い側を 3.0 → 1.0 まで下げても
  **共存は全部残る**（間隔 3.00 → 1.00）。しかも高い側は**増える**（481 → 594体）
- **斜めからも同じ。** 低0.25 / 高1.00（間隔 **0.75**）でも共存する（368 : 1211）
- **効いているのは低いほうの絶対位置。** 高い側が3のとき、境界は
  **0.55 と 0.60 の間**——0.55 で 39体、0.60 で 0体
- **相互侵入も通る。** 低0 / 高1.0 は両方向から侵入でき、同じ平衡に戻る
  （595 : 990 と 594 : 991）。陰性対照の 低0.65 / 高3.0 は両方向とも排除
- **軸の正体は「見るか見ないか」で、「どれだけ遠くを見るか」ではない。**
  視野1と視野3は同じ規則の値段違いでしかない
- 進化の着地点 0.81 と窓の端 0.55〜0.60 の距離は **0.21〜0.26**。
  25 が「0.3 ほど」と書いたものが詰まった

スクリプト: [scripts/26-position-or-gap.ts](scripts/26-position-or-gap.ts)（4節、4スレッドで17分）

## 何を分けたかったか

25 の表は、2つの規則のどちらでも説明がつく形をしていた。

| 低い側 | 絶対位置 | 間隔 | 高い側の個体数 |
|---|---|---|---|
| 0.00 | 0.00 | 3.00 | 481 |
| 0.50 | 0.50 | 2.50 | 78 |
| 0.80 | 0.80 | 2.20 | 0 |

- **規則A（絶対位置）** 低いほうが c より下なら共存。c は 0.5〜0.8 のどこか
- **規則G（間隔）** 間隔が d より広ければ共存。d は 2.2〜2.5 のどこか

**分けるには低いほうを0に固定して、高いほうを下げる。** 低いほうの絶対位置が
0 で動かないので、動くのは間隔だけになる。予測が割れるのは 低0 / 高1.5 で、
A なら共存、G なら崩壊。

### 予測を先に書いた（当たった）

**規則A が当たると読んだ。** 根拠は [22](22-vision-evolution.md) 節5 の採食統計。

| 固定視野 | 採食頻度 | 1回あたり |
|---|---|---|
| 0 | 93.0% | 0.430 |
| 1 | **15.4%** | **2.761** |
| 2 | 16.4% | 2.756 |
| 3 | 17.2% | 2.769 |

**視野1・2・3 はほとんど同じ。崖は 0 と 1 の間にしかない。**
だとすると視野1の個体と視野3の個体は「**同じ規則の値段違い**」でしかなく、
規則としては1つ。軸を作っているのは「見るか見ないか」であって
「どれだけ遠くを見るか」ではない——という筋だった。

### 第3の壊れ方も想定した（起きなかった）

高いほうを下げると実効代謝が下がる（視野3で0.475、視野1で0.425）ので、
高いほうが**強くなりすぎて低いほうを排除する**可能性を挙げていた。
21 が「同じ規則の中では R\* の低いほうが勝つ」と出しているため。
出力に「どちらが消えたか」を入れたのはこれを見るため。**排除は起きなかった。**

## 節1: 低い側を0に固定して高い側を下げる

**この節が分離の本体。** 8シード / 30000歩 / 変異なし。

| 低い側 | 高い側 | 間隔 | 高い側の個体数 | 低い側 | 高い側の取り分 |
|---|---|---|---|---|---|
| 0.00 | 3.00 | 3.00 | 481 (394-576) | 1051 | 31% |
| 0.00 | 2.50 | 2.50 | 505 (434-606) | 1039 | 33% |
| 0.00 | 2.00 | 2.00 | 533 (443-615) | 1023 | 34% |
| 0.00 | 1.50 | 1.50 | 557 (463-644) | 1013 | 35% |
| 0.00 | **1.00** | **1.00** | **594** (494-681) | 991 | **38%** |

**間隔を 3.00 から 1.00 まで縮めても、共存はまったく崩れない。**
25 は間隔 2.20 で崩壊していたが、ここでは 1.00 でも残る。**規則G は否定された。**

そして高い側は**増える**。視野3から視野1へ下げると 481 → 594体。
21 が出した「同じ規則の中では R\* の低いほうが強い」がそのまま効いている——
視野1も視野3も採食の仕方は同じで、視野1のほうが安いだけ。

> 高い側の取り分が 31% → 38% と単調に増えているのに**排除には至らない**。
> 安くなっても低い側を追い出せないのは、2種が違う規則で違う統計量に
> 制限されているから（[21](21-r-star.md) 節6・節7）。**規則が違えば
> R\* の大小は勝敗を決めない**、が別の入り口から出た。

## 節2: 窓の端は 0.55 と 0.60 の間

25 は 0.50 で 78体、0.80 で 0体を出して間を測っていなかった。高い側は3のまま。

| 低い側 | 間隔 | 高い側の個体数 | 低い側 |
|---|---|---|---|
| 0.50 | 2.50 | 78 (49-120) | 1482 | ← 25 |
| **0.55** | 2.45 | **39** (12-67) | 1522 |
| **0.60** | 2.40 | **0** (0-0) | 1562 |
| 0.65 | 2.35 | 0 (0-0) | 1557 |
| 0.70 | 2.30 | 0 (0-0) | 1553 |
| 0.75 | 2.25 | 0 (0-0) | 1548 |

**境界は 0.55 と 0.60 の間。** 0.05 の幅に収まった。

> **0.55 の 39体（最小12）は危ない。** 上位捕食者が谷で1〜5体まで落ちて
> 偶然だけで消えるのと同じ領域（[規則2](../../CLAUDE.md)）。8シードとも
> 12体を割らなかったが、**相互侵入は当てていない**ので「共存」とまでは言わない。
> 節4 で相互侵入を当てたのは 0.65（陰性対照）のほうで、0.55 ではない。

窓の端は**急**でもある。0.55 で 39体、0.60 でゼロ。25 が 0.50 → 0.80 で見た
「連続的に狭まる坂」は、端の近くでは崖になっている。

## 節3: 斜めから入っても同じ

節1 は高い側だけを動かした1本の線なので、2次元で確かめる。
2つの規則の予測が割れる点を直接踏む。

| 低い側 | 高い側 | 間隔 | 規則A の予測 | 規則G の予測 | 実際 |
|---|---|---|---|---|---|
| 0.25 | 1.50 | 1.25 | 共存 | 崩壊 | **341 : 1229 共存** |
| 0.50 | 1.50 | 1.00 | 共存 | 崩壊 | **147 : 1416 共存** |
| 0.25 | 1.00 | **0.75** | 共存 | 崩壊 | **368 : 1211 共存** |

**3点とも共存。間隔 0.75 でも壊れない。**

### 副産物: 窓は高い側にも少し依存する

低0.50 のとき、高い側が 3.00 なら 78体、**1.50 なら 147体**。ほぼ倍。
高い側を下げると少数派が楽になる。

だから**「窓の端 = 0.55〜0.60」は高い側が3のときの値**で、
高い側を下げれば端も少し上がるはず。**測っていない。**
ただし節1・節3 が示すとおり、共存するかしないかを決めているのは
圧倒的に低いほうの位置で、高いほうは少数派の**量**を動かしている。

## 節4: 相互侵入

25 で「30000歩でも数字が動かないのに実は遅い排除」（σ=0.01）を踏んでいるので、
個体数が安定しているだけでは共存と呼ばない。21 節5 と同じ判定を当てる。

| 低い側 | 高い側 | 5体から始めた側 | 高い側 | 低い側 |
|---|---|---|---|---|
| 0.00 | **1.00** | 高い側 | **595** (521-687) | 990 |
| 0.00 | **1.00** | 低い側 | **594** (502-667) | 991 |
| 0.00 | 2.00 | 高い側 | 530 (467-610) | 1026 |
| 0.00 | 2.00 | 低い側 | 532 (438-632) | 1024 |
| 0.65 | 3.00 | 高い側 | **0** (0-0) | 1557 |
| 0.65 | 3.00 | 低い側 | **0** (0-0) | 1557 |

**間隔1.00 でも両方向から侵入でき、どちらから始めても同じ平衡に戻る**
（595 と 594、節1 の 594 とも一致）。内点の安定平衡がある。

**陰性対照も効いた。** 低0.65 は両方向とも高い側が0。判定は
「何でも共存と言う」ものになっていない。

## 当たった見立てと、外した見立て

| 見立て | 実際 |
|---|---|
| （当たり）効いているのは絶対位置で、間隔ではない | 間隔 3.00 → 0.75 まで縮めても共存 |
| （当たり）視野1と視野3は同じ規則の値段違い | 節1 が単調な列を出した。安いほうが増えるが排除はしない |
| 高いほうを下げると強くなりすぎて低いほうを排除するかもしれない | **起きない。**取り分は 31% → 38% まで増えるが排除に至らない |
| （25 から持ち越し）窓の端は 0.55 か 0.78 か | **0.55 側だった。**着地点までの距離は思ったより短い |

**3つ目が外れたのは良い方向の外れ方だった。** 排除が起きていたら
「規則が違っても R\* が効く場合がある」になり、21 の結論に例外が付いていた。
起きなかったので **21 の「規則が違えば R\* は勝敗を決めない」が、
今度は高いほうを5段階動かした形で再確認された。**

## 何が言えるか

### 2本目の軸は連続量ではなく、ほぼ二値だった

[21](21-r-star.md) は「視野の有無が2本目のニッチ軸を作っている」と書き、
[22](22-vision-evolution.md) はそれを連続にして遺伝させた。
だが**軸として働いているのは連続量ではない。**

```
視野 0 ────────┬──── 1 ──── 2 ──── 3 ────
      盲目の規則 │ 見る規則（値段が違うだけ）
             境界 0.55〜0.60
```

視野1でも視野3でも「見る規則」としては同じで、変わるのは値段だけ。
軸の上の位置ではなく、**どちらの規則に属しているか**が共存を決めている。

25 が「窓には幅がある」と書いたものの正体はこれだった。幅があるのは
**低いほうがまだ盲目でいられる範囲**で、0.55 を超えると
（55%の歩で半径1を持つと）盲目の規則から抜けてしまう。

### 元の問いへの含意

> 多様性は突然変異とトライアンドエラーだけの仕組みで実現できるのか

21 が出した「行動規則の違いだけで軸が増えるなら、世界が事前に構造化されて
いる必要がない」は保たれる。26 はそれを**さらに安くした**——
必要なのは軸の上の広い分離ではなく、**規則がまたがっていること**だけ。
間隔 0.75 でも共存する。

**それでも進化はそこに留まらない。** 着地点 0.81 は境界 0.55〜0.60 の
すぐ外側で、距離は 0.21〜0.26 しかない。
**あと 0.2 ほど手前で止められれば共存が保たれる**、というのが現在地。

### 次に何を測るか

- **高いほうも動く。** 節1 は高いほうが下がるほど得をすることを示した
  （481 → 594）。[22](22-vision-evolution.md) 節6 の σ=0.01・30000歩でも
  警戒型は 3.00 → 2.80 と**下へ動いていた**。低いほうが上へ、高いほうが下へ
  動くなら、**両方が境界へ向かっている**。片方ずつ変異させて確かめられる
- **窓の端が高いほうにどれだけ依存するか。** 節3 の副産物（低0.50 で 78 対 147）。
  高いほうを1.5に置いたときの端は測っていない
- **着地点を 0.2 下げる圧力。** ここは変わらない。
  [筋6](../OVERVIEW.md#筋6--共存を作るのは死の量ではなく死の向き)の負の頻度依存を
  形質空間へ届かせる以外に道が無い（[25](25-low-hill-check.md) 節2 の対競争が
  `0.0 < 0.5 < 0.8` の一方向の梯子を出していて、自制で止まる余地は無い）

### 測り方について

**片側だけ動かす設計は、動かさなかった側との差も一緒に動かす。**
25 はそれで2つの規則を分けられなくなり、26 は**固定する側を入れ替える**だけで
分けられた。追加の機構も計器も要らなかった。

[OVERVIEW §4](../OVERVIEW.md#4-一番痛い教訓--動かした覚えのない軸が動く) の
一覧は計器の話が多いが、**26 が要したのは計器ではなく条件表の対称性**だった。
2つの量が1本の列の中で一緒に動いていないかは、走らせる前に表を縦に見れば分かる。
