# 02 構成の検証

種を足せば連鎖が伸びる、という設計が本当かを確かめた記録。
**4構成のうち2つが壊れていた。**

- 実行: `node docs/reports/scripts/02-preset-validation.ts`（4 worker で45秒）
- 条件: 8000ステップ、後半4000ステップで統計、5シード

## 全構成の現状

| 構成 | 生存 | 個体数（平均と振れ幅） |
|---|---|---|
| 基本（3層） | 5/5 | 草食 692(173-1658) / 肉食 391(133-700) |
| 競合 | 5/5 | A 576(210-1064) / B 503(123-896) / 肉食 121(8-346) |
| 雑食 | 5/5 | 草食 511(32-1730) / 雑食 438(89-859) |
| 4層 | 5/5 | 755(378-1379) / 390(220-590) / 131(67-218) |
| 追跡 | 5/5 | 草食 794(408-1470) / 肉食 243(138-317) |
| 燃費 | 5/5 | 警戒型 523(233-1086) / 無警戒型 448(165-860) / 肉食 379(269-483) |
| 進化 | 5/5 | 草食 722(558-874) / 肉食 350(260-440) |
| 空腹 | 5/5 | 草食 821(496-1168) / 肉食 308(215-416) |

「進化」と「空腹」は後から足した構成で、経緯はそれぞれ
[10](10-speed-evolution.md) と [11](11-hunger.md) にある。
それ以外の6構成の数値は、両方を入れる前と**1つも変わっていない**
（`hungerThreshold` の既定が0で分岐に入らず、`mutation` を書かない種は
そもそも乱数を消費しないため）。

以下は、ここに至るまでに直したもの。

## 壊れていた1: 雑食

最初に書いた雑食構成では、**草食動物が250〜420ステップで絶滅**していた。
雑食動物だけが924体で安定し、実質「草食動物が1種いるだけ」の生態系になっていた。

原因は雑食動物の**採食量2 が自分の代謝0.7 を上回っていた**こと。
草を食べるだけで黒字になるので狩る必要がなくなり、
競争（同じ草を食べる）と捕食（草食動物を食べる）の二重の圧力で相手を排除していた。

採食量を振ると閾値がはっきり出る。

| 雑食の採食量 | 生存 | 草食動物 | 雑食動物 |
|---|---|---|---|
| 3 | 0/5 | **0** | 925 |
| 2 | 0/5 | **0** | 924 |
| 1.2 | 0/5 | **0** | 915 |
| 0.8 | 0/5 | **0** | 828 |
| 0.4 | 5/5 | 511 | 438 |

境目は代謝の0.7。**採食量が代謝を下回ると草だけでは増えられなくなり**、
狩らなければならなくなる。既定を0.4にして、草は餓死を防ぐ保険として働くようにした。

## 壊れていた2: 4層の逆ピラミッド

4層構成は全シードで生き残っていたが、個体数が

```
草食 932  >  中位捕食者 209  <  頂点捕食者 219
```

となっていた。**頂点捕食者が中位捕食者より多い。** 生態系としておかしい。

原因は頂点捕食者の代謝0.3が低すぎて、餌の量にほとんど制約されていなかったこと。
代謝を上げていくと正しい形になる。

| 頂点の代謝 | 生存 | 草食 | 中位 | 頂点 | 形 |
|---|---|---|---|---|---|
| 0.30 | 5/5 | 932 | 209 | **219** | 逆ピラミッド |
| 0.45 | 5/5 | 821 | 311 | 175 | ピラミッド |
| 0.55 | 5/5 | 755 | 390 | 131 | ピラミッド（採用） |
| 0.65 | 0/5 | 697 | 528 | **0** | 頂点が絶滅 |
| 0.75 | 0/5 | 744 | 496 | **0** | 頂点が絶滅 |

0.55と0.65の間に崖がある。**最上位は生き残れる幅が狭い**という、
実際の生態系でも言われることがそのまま出た。

なおこの構成は既定値でも完全に安全ではない。8シードで測ると1回崩壊する
（[04](04-metabolism-stability.md) 参照）。上位捕食者を含む系は本質的に脆い。

## 壊れていなかったが確認したこと: 競合

「捕食者が優占種を抑えるから劣位種が生き残れる」という想定で作った構成。
本当にそうなのかは、**捕食者を消してみないと分からない**。

| 条件 | 生存 | 草食A（強） | 草食B（弱） |
|---|---|---|---|
| 捕食者あり | 5/5 | 576 | 503 |
| 捕食者なし（初期0） | 0/5 | **1298** | **0** |

捕食者を消すと草食Bは全シードで絶滅し、Aが1298まで独占した。
共存は捕食者が作り出していたもので、想定どおりだった。

競争の勝者を捕食者が叩くことで多様性が保たれる、キーストーン捕食と呼ばれる現象。
UI上でも肉食の初期個体数を0にしてリセットすれば再現できる。

## 分かったこと

**4構成のうち2つが壊れていて、どちらも型検査を通り、画面上では動いていた。**

雑食は「雑食動物が元気に増えている」ようにしか見えないし、
4層は3種とも生き残っているので一見成功に見える。
個体数の内訳を数字で見て初めて壊れていると分かった。

一方で、設計の狙いどおりだった部分もある。
種を追加するのに `presets.ts` 以外は触っていない。
スライダーもグラフの系列も種定義から自動生成されるので、UI側の変更は不要だった。
