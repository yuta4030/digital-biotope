# 06 豊穣化

環境を豊かにすると捕食者-被食者系が不安定になる、という現象がこのモデルに出るのか。
**最初に誤った結論を出したので、その訂正も含めて記録する。**

- 実行: `node docs/reports/scripts/06-enrichment.ts`（約5分）
- 条件: 6000ステップ、後半3000ステップで統計、8シード

## 最初に出した誤った結論

[03](03-vision-and-pursuit.md) の探索中に、こういうデータを見た。

```
成功率0.03 利得30 草食繁殖0.08  OK 4/4   草食721  肉食417
成功率0.05 利得30 草食繁殖0.12  -- 0/4   草食  0  肉食  0
成功率0.05 利得30 草食繁殖0.16  -- 0/4   草食  0  肉食  0
```

これを見て「草食の繁殖確率を上げると生態系が壊れる。豊穣化のパラドックスだ」と報告した。

**比較になっていない。** 上の行は成功率0.03、下は0.05で、捕食者の強さが違う。
しかも同じ実験の別の行を見れば、成功率0.05・繁殖0.08（つまり繁殖を上げる前）が
すでに `0/4` で壊れていた。壊れた設定同士を比べて、
動かしていないパラメータのせいにしていた。

## 正しく測る

豊穣化は本来「餌の生産量を増やす」ことを指す。このモデルなら草の回復速度。
繁殖確率とは別物なので、両方を分けて測り直した。

### 草の回復速度を上げる（基本構成）

| 回復速度 | 草食の理論上限 | 生存 | 草食の振れ幅 | 肉食の振れ幅 |
|---|---|---|---|---|
| 0.04 | 720 | 8/8 | 429 - 759 | 115 - 229 |
| 0.06（既定） | 1080 | 8/8 | 173 - 1658 | 133 - 687 |
| 0.09 | 1620 | 8/8 | 93 - 2185 | 119 - 1043 |
| 0.12 | 2160 | 8/8 | 73 - 2539 | 91 - 1286 |
| 0.18 | 3240 | 8/8 | 29 - 2962 | 51 - 1593 |
| 0.25 | 4500 | **5/8** | **0** - 4966 | **0** - 1793 |

**振れ幅が単調に広がり、既定の4倍で崩壊する。** 谷が 429 → 29 → 0 と浅くなっていき、
0に当たった時点で絶滅する。3回の崩壊はステップ208、2820、3429で起きた。

これは豊穣化のパラドックスと呼ばれる現象そのもの。餌を増やすと平均個体数は増えるが、
振動が激しくなって絶滅しやすくなる。

### 草食の繁殖確率を上げる（基本構成）

| 繁殖確率 | 生存 | 草食の振れ幅 | 肉食 |
|---|---|---|---|
| 0.08（既定） | 8/8 | 173 - 1658 | 399 |
| 0.12 | 8/8 | 166 - 1715 | 456 |
| 0.16 | 8/8 | 177 - 1693 | 498 |
| 0.20 | 8/8 | 169 - 1650 | 523 |
| 0.25 | 8/8 | 180 - 1601 | 559 |

**まったく不安定化しない。** 振れ幅は 173-1658 から 180-1601 とほぼ変わらず、
3倍に増やしても8/8で生き残る。変わるのは配分だけで、
肉食が 399 → 559 に増え、草食はわずかに減る。

理屈は通っている。繁殖確率は**上限を変えない**。上限を決めるのは草の生産量と代謝で、
繁殖確率はそこへ到達する速さを変えるだけ。豊穣化とは別の操作だった。

つまり最初の報告は、**現象の名前も因果も取り違えていた。**

## 追跡構成では豊穣化しても壊れない

同じことを「追跡」構成（捕獲成功率0.04）でやると、結果が変わる。

| 回復速度 | 生存 | 草食 | 肉食 |
|---|---|---|---|
| 0.06（既定） | 8/8 | 792 (367-1379) | 244 (170-329) |
| 0.12 | 8/8 | 1206 (642-2036) | 633 (422-766) |
| 0.18 | 8/8 | 1578 (597-2648) | 931 (528-1169) |
| 0.25 | 8/8 | **2092 (601-4291)** | 1221 (426-1636) |

基本構成が崩壊した0.25でも 8/8 で生き残る。谷も601と深くない。

理由は**捕獲成功率が上限として効いている**こと。基本構成の捕食者は
同じセルに獲物がいれば必ず食べるので、獲物が増えた分だけ際限なく食べて増える。
追跡構成の捕食者は25回に1回しか成功しないため、獲物が増えても捕食速度が頭打ちになる。

この頭打ちが振動の暴走を抑えている。生態学でいう飽和型の機能の反応が
豊穣化のパラドックスを緩和する、という筋道と一致する。

繁殖確率のほうは追跡構成でも同じく無害だった（0.25まで8/8、振れ幅ほぼ不変）。

## まとめ

| 操作 | 基本構成 | 追跡構成 |
|---|---|---|
| 草の回復速度を4倍 | **5/8 に崩壊** | 8/8 |
| 草食の繁殖確率を3倍 | 8/8 | 8/8 |

- 豊穣化のパラドックスは**確かに出る**が、餌の生産量を増やしたときだけ
- 消費者の繁殖速度を上げても不安定化しない
- 捕獲成功率が低いと豊穣化に強くなる

## 分かったこと

誤った報告をした原因は、**探索の途中経過をそのまま結論にしたこと**だった。

パラメータを探している最中のデータは、複数の軸が同時に動いている。
そこから1つの軸だけを取り出して因果を語るには、
**他の軸を固定した実験を別に組む**必要がある。

今回は既知の現象名（豊穣化のパラドックス）が頭にあったぶん、
それらしいデータを見た時点で確認を省いてしまった。
名前を知っている現象ほど、当てはめる前に測ったほうがいい。
