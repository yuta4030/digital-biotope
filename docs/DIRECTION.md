# これから何をやるか

**ここまでで何が分かったかは [OVERVIEW](OVERVIEW.md) にある。**
このファイルは前を向いている部分だけを持つ——いまの前提、次の一手、
やらないと決めたもの、そして計画がどうずれたか。

## 元の問い

> 上位層は適応できる世界が狭いという結果が出た。
> では今の地球が幅広い多様性と関係性を実現できたのはなぜか。
> 多様性は突然変異とトライアンドエラーだけの仕組みで実現できるのか。

## 前提の置き直し

09 までの全レポートで、成功の指標を**「8シード全部で既存種が生き残ること」**に
していた。これは明示していない選択で、しかも偏っている。**既存種の存続**と
**新しい種が入り込める余地**は別物で、しばしば逆を向く。
安定した平衡は、居座っている側にとって最も守りが固い状態でもある。

置き直した前提はこう。

> **繁栄にはある程度の安定が必須で、その上で許容できる範囲の揺らぎが必要になる。**

揺らぎ自体は悪ではない。希少な変異体は、平衡状態では既存種の壁を越えられないが、
既存種が谷に落ちた瞬間なら食い込める。**揺らぎが局所最適から抜ける機会を作る**
という筋で、生態学でいう storage effect（貯蔵効果）に近い。

ただし揺らぎは両刃で、個体数の少ない変異体は谷で消える。
だから「どのくらいの揺らぎなら機会になり、どこから殺しにかかるか」が本題になる。
安定と揺らぎのどちらかではなく、**その配分**を測る。

### 予想表

ここから出る予想。10 以降のレポートがずっと参照している。

> 揺らぎ **小** → 定着率は低い / **中** → 高い / **大** → 低い

状態は「**前半は再現、後半は別の形で現れた**」（[14](reports/14-mass-death.md)）。
揺らぎを削ると定着率は下がる（中立 9.5% → 7.2%）。だが大きくしていっても
定着率が折り返す点は無く、先に**世界のほうが壊れる**。
「大きすぎる揺らぎは変異体を殺す」の前に「大きすぎる揺らぎは系を殺す」が来る。
つまり後半は、予想が外れたというより**指標が定義できなくなる領域**に入る。

12・13 では測れていない。揺らぎの大きさを世界間で変える手段が無かったため
（下記 C'）。両方が測れたのは 14 のつまみができてから。

この前提のもとで 12・13・14 を走らせた。結果は
[OVERVIEW の筋5](OVERVIEW.md#筋5--揺らぎは局所最適から抜ける機会を作るただし両刃) にある。
**前提そのものは維持されている**が、後半（大きすぎる揺らぎ）は
変異体が死ぬより先に世界が壊れる形で現れた。

## モデルはシンプルに保つ

要素を増やすほど何が要因か分からなくなる。実際、これまで覆った結論5件のうち
3件は「動かした覚えのない軸が動いていた」ことが原因だった
（[OVERVIEW §4](OVERVIEW.md#4-一番痛い教訓--動かした覚えのない軸が動く)）。
**足す軸は1本ずつ、対照実験とセットで。**

この方針から、検討して**やらないと決めたもの**:

- **個体へのバッファ（休眠・寿命延長など）** — やらない。
  生きている間はそれ自体が十分バッファとして機能している。
  調整可能な軸を増やすと、揺らぎとバッファの効果が混ざる
- **種ごとの応答の差を手で作る** — やらない。変異システムの中で自然に出るべきもの

## 次にやること

### 負の頻度依存（kill-the-winner）

寄生・感染症に相当する、**増えた種ほど叩かれる**圧力。理由は2つある。

1. **共存を作る機構。** [10](reports/10-speed-evolution.md) が
   「二つの戦略を共存させるには負の頻度依存が要る。この構成にはそれが無い」で
   終わっていて、[13](reports/13-escape.md) は 10 の分岐が**遷移**であって
   共存ではないことを裏づけた（1つの集団はどちらかの丘に落ちる）。
   地球で最も強力な多様性の維持機構でもある
2. **揺らぎのつまみ問題の出口。** 増えた種ほど叩かれる圧力は捕食とは別系統で
   個体数を振るので、丘の位置を動かさずに揺らぎを動かせる可能性がある。
   14 の大量死は「全種を叩くと捕食圧が下がる」という形で交絡が戻ってきたが、
   頻度依存なら叩く相手が増えた種に限られる

**入れるときの条件。** 14 で踏んだのと同じ轍を避けるため、
「**それが何を一緒に動かすか**」を数える手段を機構と同時に作る。
最低限、捕食者の頭数・速度の収束先・1ステップあたりの実際の除去数を
毎回出す形にしておくこと。14 では全種を叩いたときの丘のずれ（2.70 → 2.25）が
それで即座に見えていたはずだった。

## まだ手を付けていないもの

優先度順ではなく、思いついた順。

- **捕食以外の種間関係** — `types.ts` の種間関係は `preys` だけで、
  「食べる」以外が型として存在しない。地球の多様性の跳躍（細胞内共生・
  多細胞化・送粉）はどれも捕食ではなく**合体**で起きている
- **分解者を種として実装する** — [09](reports/09-detritus-buffer.md) で
  在庫としてのバッファは効かないと分かったが、分解者は**動く**ので
  死骸を食った場所と自分が死ぬ場所がずれる。09で効いた「空間的に撒く」を
  自前でやる装置になりうる
- **代謝の変異** — 10 は速度でやった。単調な坂に崖が付いた軸なので、
  速度（内点で釣り合う）とは別の形が出るはず
- **速度以外の形質を遺伝させる** — 視野や捕獲成功率を遺伝させれば
  「目と足のどちらに投資するか」を選ばせられる。ただし新しい形質には
  **代償を用意しないと上限まで走り去る**（10で確認済み）

## 計画と実際のずれ

当初の計画は実装の段階で何度も変わった。**古い手順は指示としては残さない。**
どちらが現行か分からなくなるため。ずれた点だけ記録する。

| 計画 | 実際 | 理由 |
|---|---|---|
| 代謝を変異させる | 速度を変異させた（[10](reports/10-speed-evolution.md)） | 利益と代償の釣り合いが式で書ける。代謝はまだ未着手 |
| 一様乱数で変異。正規分布は足さない | `rng.normal()` を足して正規ノイズ | 端数の確率繰り上げと合わせて、格子の上で連続値を扱うため |
| 侵入は10体 | 1体（[12](reports/12-invasion.md)） | この模型に集中の利点が無く、10体だと「10本の独立系統」か「共倒れ」になる |
| 平均を揃えて揺らぎだけ違う世界を作る | 捕食側では作れなかった（13）／大量死で作れた（[14](reports/14-mass-death.md)） | 捕食は丘と揺らぎの両方を作るので分離できない。捕食の外側から叩く必要があった |
| 定着＝閾値到達 | 閾値到達＋時間で追跡（[12](reports/12-invasion.md)） | 30体到達は運の区間の途中で、選択が効くのは +1000ステップから |
| 大量死は形質を見ないので丘を動かさない | 全種を叩くと動く（14） | 捕食者も減るので捕食圧が下がる。対象を草食だけに絞れば成立する |

計画の段階で正しかったのは**回帰の約束**（変異や大量死を使わない構成が乱数を1つも
消費しないこと）だけで、これは 10・11・12・14 の全部で守られている。
