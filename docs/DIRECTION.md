# これから何をやるか

**ここまでで何が分かったかは [OVERVIEW](OVERVIEW.md) にある。**
このファイルは前を向いている部分だけを持つ——いまの前提、次の一手、
やらないと決めたもの、そして計画がどうずれたか。

## 元の問い

> 上位層は適応できる世界が狭いという結果が出た。
> では今の地球が幅広い多様性と関係性を実現できたのはなぜか。
> 多様性は突然変異とトライアンドエラーだけの仕組みで実現できるのか。

## 前提の置き直し

09 までの全レポートで、成功の指標を**「8シード全部で既存種が生き残ること」**に
していた。これは明示していない選択で、しかも偏っている。**既存種の存続**と
**新しい種が入り込める余地**は別物で、しばしば逆を向く。
安定した平衡は、居座っている側にとって最も守りが固い状態でもある。

置き直した前提はこう。

> **繁栄にはある程度の安定が必須で、その上で許容できる範囲の揺らぎが必要になる。**

揺らぎ自体は悪ではない。希少な変異体は、平衡状態では既存種の壁を越えられないが、
既存種が谷に落ちた瞬間なら食い込める。**揺らぎが局所最適から抜ける機会を作る**
という筋で、生態学でいう storage effect（貯蔵効果）に近い。

ただし揺らぎは両刃で、個体数の少ない変異体は谷で消える。
だから「どのくらいの揺らぎなら機会になり、どこから殺しにかかるか」が本題になる。
安定と揺らぎのどちらかではなく、**その配分**を測る。

### 予想表

ここから出る予想。10 以降のレポートがずっと参照している。

> 揺らぎ **小** → 定着率は低い / **中** → 高い / **大** → 低い

状態は「**前半は再現、後半は別の形で現れた**」（[14](reports/14-mass-death.md)）。
揺らぎを削ると定着率は下がる（中立 9.5% → 7.2%）。だが大きくしていっても
定着率が折り返す点は無く、先に**世界のほうが壊れる**。
「大きすぎる揺らぎは変異体を殺す」の前に「大きすぎる揺らぎは系を殺す」が来る。
つまり後半は、予想が外れたというより**指標が定義できなくなる領域**に入る。

12・13 では測れていない。揺らぎの大きさを世界間で変える手段が無かったため
（下記 C'）。両方が測れたのは 14 のつまみができてから。

この前提のもとで 12・13・14 を走らせた。結果は
[OVERVIEW の筋5](OVERVIEW.md#筋5--揺らぎは局所最適から抜ける機会を作るただし両刃) にある。
**前提そのものは維持されている**が、後半（大きすぎる揺らぎ）は
変異体が死ぬより先に世界が壊れる形で現れた。

## モデルはシンプルに保つ

要素を増やすほど何が要因か分からなくなる。実際、これまで覆った結論5件のうち
3件は「動かした覚えのない軸が動いていた」ことが原因だった
（[OVERVIEW §4](OVERVIEW.md#4-一番痛い教訓--動かした覚えのない軸が動く)）。
**足す軸は1本ずつ、対照実験とセットで。**

この方針から、検討して**やらないと決めたもの**:

- **個体へのバッファ（休眠・寿命延長など）** — やらない。
  生きている間はそれ自体が十分バッファとして機能している。
  調整可能な軸を増やすと、揺らぎとバッファの効果が混ざる
- **種ごとの応答の差を手で作る** — やらない。変異システムの中で自然に出るべきもの

## 負の頻度依存（kill-the-winner）— 入った

3段構えで測った。[15](reports/15-frequency-dependence.md) が対照、
[16](reports/16-crowding.md) が足場、[17](reports/17-infection.md) が本命。

| | 問い | 結果 |
|---|---|---|
| **15** | 均等に減らすだけで共存するか | **しない。** 除去率を12倍、塊を16倍に振っても全滅。動くのは絶滅の時刻だけ |
| **16** | 頻度依存を手で書けば共存するか | **する**（rate 0.1 以上で 8/8）。ただし共存条件を式で置いただけで機構ではない |
| **17** | 接触感染で、書かずに出るか | **出る**（伝染確率 0.8 以上で 8/8、A 701 / B 345） |

**対照が両方とも効いている。** 16 の `scope: 'all'` も 17 の `scope: 'all'` も、
機構もつまみも同一で「誰の密度を見るか / 誰に移るか」だけが違う。そして
**どちらも対照のほうが多く殺しているのに共存しない**（17 の tr=1.0 で
1.39%/歩 対 0.95%/歩）。効いているのは死の量ではなく死の向き。

**段1が出した的に段2が当たった。** 16 が共存点でAから 1.23%/歩 を取り除いていて、
17 は 0.90%/歩。別々の機構が同じ水準に落ちている。

### 予想と違った点

「増えた種ほど叩かれる」ではなく「**少ない種が病気から逃げ切る**」だった。
病原体の維持には宿主密度の下限があるので、Aだけが感染率45%で病気を抱え、
Bは2〜6%しか感染しない。効果の向きは同じだが、連続的な調整ではなく**閾値**。

### 残っている条件

- **伝染確率 0.8〜1.0 が要る。** 密度 0.12個体/セルでは同セル遭遇が
  1歩あたり数%しかないので、1回あたりの確実さで埋めている。
  密度を上げれば閾値が下がるはずだが測っていない
- **速度の分岐（[10](reports/10-speed-evolution.md) の目型・足型）には届かない。**
  同一種内の形質の分布なので、種を単位にした病原体は区別しない

## 次にやること

### 揺らぎのつまみとして使えるか — 測った。使えない

[19](reports/19-infection-as-noise.md) で決着した。**このファイルがずっと掲げていた
見立ては外れ。**

> 増えた種ほど叩かれる圧力は捕食とは別系統で個体数を振るので、
> 丘の位置を動かさずに揺らぎを動かせる可能性がある

前半（丘を動かさない）は当たった。速度は 2.74 のまま動かない。
**後半（揺らぎを動かせる）が成り立たない。** 谷の深さは 0.807 → 0.741 までしか
動かず、同じ量を無作為に取り除いた対照（0.762）と差が無い。

原因は密度依存でも宿主特異性でもなく**削り方**だった。同じ除去率でも
100歩に1回まとめて叩くと谷の深さが 0.350 まで落ちる（毎歩なら 0.783）。
**揺らぎを作っているのはまとめて叩くことで、誰を叩くかではない。**

そして**丘を動かさない理由と揺らぎを作れない理由が同じ**——連続的で穏やかだから。
つまみとして使うには、この2つを分ける必要がある。
病原体で塊を作るなら潜伏期間か獲得免疫が要る（いまは SI モデルで波が立たない）。

### 二つの丘を共存させる

[10](reports/10-speed-evolution.md) が終わった場所。17 の病原体は種を単位に
しているので、目型と足型は区別しない。**形質が似ているほど移りやすい**形にすれば
届くが、それは形質空間での自己抑制を手で書くのに近い
（16 が種の空間でやったことと同じ）。

先に 17 のままで「速度が遺伝する構成に宿主特異的な病原体を入れる」を測って、
何も起きないことを確かめてからのほうがいい。

## 環境は軸になるか — 2回塞がった

[07](reports/07-grass-patches.md) は**資源の分布**を不均質にして、共存はむしろ壊れた。
そこから出した一般化は「環境が軸になるのは**誰がどこを得意とするかが違う**ときだけ」で、
07にはその差が無かった（草食2種は同じ規則で草を探す）。

[20](reports/20-terrain.md) はその差を形質から出した。移動の代償をセルごとに変えると、
速度の限界代償がセルで違うので、速い個体と遅い個体で得意な場所が入れ替わる。
種ごとの応答も誰かの密度も書いていない。**それでも分かれるのは個体数だけだった**
（平地268 対 険地221 に対して速度は 2.80 対 2.77）。

捕食圧という強いレバーを経由させても届かなかった。捕食者も進化させると捕食者は
山を捨てるので（152 対 79）**山は捕食圧の低い場所になる**が、
草食の速度差は 0.11 で集団内のばらつき 0.40 に埋もれる。

### 見立て — 逃げられる圧力は形質を分けない

まだ測っていない。

17 の感染が効いたのは、圧力が**種の密度**という個体が動いても付いてくる性質に
結合していたから。増えた種の個体はどこへ行っても同型に囲まれる。
地形は逃げられる。実現倍率が1を割る（0.95〜0.99）のがその証拠で、
**逃げた結果として個体数は分かれ、逃げられるからこそ形質は分かれない。**

正しければ、環境が軸になる条件は「不均質であること」でも「形質と結合していること」でもなく
**そこから離れられないこと**になる。07・20が失敗して16・17が成功した理由の
統一的な説明になりうるが、08 で「名前を知っている現象を当てはめて誤報した」ことがあるので
測るまでは見立てのまま。

### 残っているのはニッチ軸を増やすこと

この模型の資源は `eatsGrass` の1本きりで、**07も20も同じ軸の空間分布を変えていた**。
ニッチ軸そのものを増やしたことは一度も無い。

資源を2種類にして得意を逆にする（資源比・R*）なら、各種が自分の得意な資源を減らすので
自己抑制が**消費と資源の力学から出る**。16のように共存条件を式で置くのではなく、
17と同じ「機構から出る」形になる。環境由来の共存で唯一まだ試していない形。

## まだ手を付けていないもの

優先度順ではなく、思いついた順。

- **捕食以外の種間関係** — `types.ts` の種間関係は `preys` だけで、
  「食べる」以外が型として存在しない。地球の多様性の跳躍（細胞内共生・
  多細胞化・送粉）はどれも捕食ではなく**合体**で起きている
- **分解者を種として実装する** — [09](reports/09-detritus-buffer.md) で
  在庫としてのバッファは効かないと分かったが、分解者は**動く**ので
  死骸を食った場所と自分が死ぬ場所がずれる。09で効いた「空間的に撒く」を
  自前でやる装置になりうる
- **代謝の変異** — 10 は速度でやった。単調な坂に崖が付いた軸なので、
  速度（内点で釣り合う）とは別の形が出るはず
- **捕食者の進化を単独で測る** — [20](reports/20-terrain.md) 節7 で捕食者にも
  変異を入れたが、地形と同時に入れたので分離が弱い。平坦な世界では
  **捕食者の速度は 2.04 に収束する**（既定の手置き 2.0 とほぼ一致）ところまでは
  見えている。軍拡がどこで釣り合うかはそれ自体が問いになる
- **速度以外の形質を遺伝させる** — 視野や捕獲成功率を遺伝させれば
  「目と足のどちらに投資するか」を選ばせられる。ただし新しい形質には
  **代償を用意しないと上限まで走り去る**（10で確認済み）

## 計画と実際のずれ

当初の計画は実装の段階で何度も変わった。**古い手順は指示としては残さない。**
どちらが現行か分からなくなるため。ずれた点だけ記録する。

| 計画 | 実際 | 理由 |
|---|---|---|
| 代謝を変異させる | 速度を変異させた（[10](reports/10-speed-evolution.md)） | 利益と代償の釣り合いが式で書ける。代謝はまだ未着手 |
| 一様乱数で変異。正規分布は足さない | `rng.normal()` を足して正規ノイズ | 端数の確率繰り上げと合わせて、格子の上で連続値を扱うため |
| 侵入は10体 | 1体（[12](reports/12-invasion.md)） | この模型に集中の利点が無く、10体だと「10本の独立系統」か「共倒れ」になる |
| 平均を揃えて揺らぎだけ違う世界を作る | 捕食側では作れなかった（13）／大量死で作れた（[14](reports/14-mass-death.md)） | 捕食は丘と揺らぎの両方を作るので分離できない。捕食の外側から叩く必要があった |
| 定着＝閾値到達 | 閾値到達＋時間で追跡（[12](reports/12-invasion.md)） | 30体到達は運の区間の途中で、選択が効くのは +1000ステップから |
| 大量死は形質を見ないので丘を動かさない | 全種を叩くと動く（14） | 捕食者も減るので捕食圧が下がる。対象を草食だけに絞れば成立する |

計画の段階で正しかったのは**回帰の約束**（変異や大量死を使わない構成が乱数を1つも
消費しないこと）だけで、これは 10・11・12・14 の全部で守られている。
